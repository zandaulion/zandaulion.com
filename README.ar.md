# Zandaulion

ورشة مرحة للأفكار الفضولية: تطبيقات وألعاب وأدوات صغيرة تنتظر اكتشافك.

**[قم بزيارة zandaulion.com](https://zandaulion.com/)** · [المجموعة الرومانية](https://zandaulion.com/ro/index.html)

يحتوي هذا المستودع على موقع Zandaulion: مجموعة قابلة للبحث مكونة من 20 مشروعًا، وصفحات مشاريع فردية، ومحرر الرسوم البيانية التفاعلي Sankey. الصفحة الرئيسية وكل صفحة مشروع متاحة بـ 12 لغة. الموقع ثابت HTML، CSS، وفانيليا JavaScript، مستضاف على GitHub Pages.

## ترجمات README

يتوفر هذا الملف التمهيدي بنفس اللغات الـ 12 المتوفرة على الموقع الإلكتروني. استخدم روابط اللغة في الأعلى لتبديل الإصدارات. تعيش اللغة الإنجليزية في `README.md`؛ تستخدم الإصدارات المترجمة أسماء ملفات مثل `README.ro.md` و`README.ar.md`.

قم بتحرير الملف التمهيدي باللغة الإنجليزية والكتالوجات المقابلة في `locales/readme/`، ثم قم بتشغيل `python scripts/build_readmes.py` لإعادة إنشاء الملفات المترجمة. استخدم `python scripts/build_readmes.py --check` للكشف عن الملفات القديمة أو الترجمات المفقودة. تقوم علامة `--fetch` الاختيارية بإعداد مسودات الترجمة المفقودة من خلال نفس خدمة الترجمة Google المستخدمة لنص المشروع. يتم الاحتفاظ بالأوامر والمسارات وأمثلة التعليمات البرمجية ووجهات الارتباط.

## محتويات المشروع

- مجموعة تحتوي على مرشحات الفئات والبحث غير الحساس لللكنة والاكتشاف العشوائي.
- أوصاف المشروع، وروابط الإطلاق والمصدر، ومعارض لقطات الشاشة، والمشاريع ذات الصلة.
- معارض الصور التي يمكن الوصول إليها باستخدام لوحة المفاتيح مع التسميات التوضيحية وعناصر التحكم السابقة/التالية وإيماءات اللمس.
- محرر Sankey مزود بتحرير العقدة/الارتباط وتصدير الصور واستيراد/تصدير JSON.
- اختيار اللغة، والتفضيلات المحفوظة، واكتشاف لغة المتصفح، والتخطيط باللغة العربية من اليمين إلى اليسار.
- إشعارات الخصوصية الموجودة باللغة الإنجليزية على عناوين URL المسجلة بالفعل في Google Play.

## المعاينة محليًا

قم بتشغيل هذه الأوامر من جذر المستودع. هناك حاجة إلى Python للمولد والفحوصات؛ تستخدم البرامج النصية Python المكتبة القياسية فقط. هناك حاجة إلى Node.js المزود بمشغل الاختبار المدمج لإجراء اختبارات اللغة. لا توجد خطوة تثبيت npm أو أداة تجميع الواجهة الأمامية.

<div dir="ltr">

```sh
python scripts/build_locales.py
python -m http.server 8765 --bind 127.0.0.1
```

</div>

افتح [الصفحة الرئيسية المحلية](http://127.0.0.1:8765/index.html)، أو استخدم [الإنجليزية الصريحة](http://127.0.0.1:8765/index.html?lang=en-US) أو [Romanian](http://127.0.0.1:8765/ro/index.html) لتجاوز التحديد التلقائي للغة.

تم تصميم HTML أيضًا للتصفح المباشر للملفات. افتح `index.html`، وليس مجلد اللغة؛ يستخدم التنقل أسماء ملفات صريحة لتجنب قوائم الدليل. البرامج النصية للغة هي نصوص عادية وليست وحدات ES. تعد معاينة HTTP المحلية هي الطريقة الموصى بها لمراجعة التغييرات.

تحتفظ صفحات المشروع المترجمة بنفس اسم الملف تحت بادئة اللغة، مثل `/fr/kerfloom.html` أو `/ja/plate.html`. يؤدي تبديل اللغة إلى الحفاظ على المشروع الحالي ومثبت القسم. تبقى روابط المجموعة والمشروعات ذات الصلة باللغة المحددة. تحتوي كل صفحة رئيسية وصفحة مشروع على إعلان لغة وعنوان URL أساسي وروابط `hreflang` المتبادلة.

مسار اللغة الصريح، مثل `/ro/`، له الأسبقية دائمًا. في صفحة الإدخال الرئيسية فقط (`/` أو `/index.html`)، يتبع التحديد هذا الترتيب:

1. خيار `?lang=` صريح ومدعوم.
2. تفضيلات اللغة المحفوظة.
3. أول تفضيل متصفح مدعوم من `navigator.languages`.
4. الإنجليزية في حالة عدم تطابق اللغة المدعومة.

تتطابق المتغيرات الإقليمية مع لغتها الأساسية: على سبيل المثال، يحدد `fr-CA` اللغة الفرنسية. تشتمل الروابط الإنجليزية على `?lang=en-US`، لذلك يعمل الاختيار الصريح حتى في حالة عدم توفر مساحة تخزين في المتصفح. تحافظ عمليات إعادة توجيه صفحة الإدخال على نقاط ارتساء القسم ومعلمات الاستعلام الأخرى. لا يتم إعادة توجيه عناوين URL الخاصة بالمشروع والخصوصية أبدًا بناءً على لغة المتصفح.

روابط لغة الصفحة الرئيسية موجودة في HTML وتعمل بدون JavaScript. تستخدم رؤوس المشروع ومنتقي اللغة وعناصر تحكم المعرض ومحرر Sankey JavaScript. تحمل روابط مشروع الملف المحلي اللغة المحددة في عنوان URL لأن المتصفحات قد تعزل مساحة التخزين لكل ملف.

## تحرير الصفحات وتوليدها

| ما يجب تغييره | المصدر للتحرير |
| --- | --- |
| تخطيط الصفحة الرئيسية | `templates/home.html` |
| نص الصفحة الرئيسية بكل لغة | `locales/<locale>.json` |
| محتوى المشروع وتخطيطه باللغة الإنجليزية | ملفات المشروع الجذر HTML، مثل `kerfloom.html` |
| محتوى المشروع مترجم | `locales/projects/<locale>/<project>.json` |
| عناصر التحكم في المعرض ورسائل المحرر | `locales/projects/<locale>/common.json` |
| تصحيحات الترجمة القابلة لإعادة الاستخدام | `locales/projects/overrides.json` |
| اللغات المدعومة وبادئات URL | `scripts/site_locales.py` |
| تغطية المشروع وتقديم الترجمة | `scripts/project_locales.py` |
| عرض مشترك | `workshop.css` و`project.css` |
| الجمع والمشروع والسلوك اللغوي | `workshop.js`، `project.js`، و`language.js` |
| سلوك محرر Sankey | `sankey.js` |

بعد تحرير محتوى المصدر أو الكتالوجات، قم بإعادة إنشاء الموقع:

<div dir="ltr">

```sh
python scripts/build_locales.py
```

</div>

ينتج المولد 12 صفحة رئيسية و220 صفحة مشروع مترجمة و`language-data.js`. ويحتفظ أيضًا بروابط أساسية وروابط بلغات بديلة في صفحات المشروع العشرين باللغة الإنجليزية. ربط هذه المخرجات المتولدة بمصادرها؛ يخدمهم GitHub Pages مباشرة دون تشغيل مولد Python.

لا تقم بتحرير الصفحات الرئيسية التي تم إنشاؤها أو HTML المترجمة أو `language-data.js` مباشرة: يستبدل التجديد تلك التعديلات. يجب أن تحتوي كتالوجات الصفحة الرئيسية على مفاتيح غير فارغة متطابقة. تستخدم كتالوجات المشروع النص المصدر كمفاتيح، لذا فإن التغييرات في النسخة الإنجليزية تتطلب تحديثات الترجمة المقابلة. الترجمات المفقودة تفشل في الإنشاء.

### صيانة الترجمات

تم إعداد مسودات ترجمة المشروع باستخدام خدمة الترجمة الخاصة بـ Google، ثم تم تحسين الصياغة المشتركة وعناصر التحكم في المعرض وأسماء المنتجات والعبارات الفنية المحددة. تم الاحتفاظ بالترجمات الرومانية السابقة. لا تزال مراجعة المتحدث الأصلي مفيدة، خاصة بالنسبة للمصطلحات التقنية. تحتفظ أسماء التطبيقات ولقطات الشاشة والمعرفات الفنية بشكلها الأصلي.

يمكن لنص التأليف الاختياري إعداد الترجمات المفقودة للغة واحدة:

<div dir="ltr">

```sh
python scripts/translate_projects.py --fetch --language ro
```

</div>

احذف `--language ro` لمعالجة كافة اللغات المترجمة. تسمح علامة `--fetch` بإرسال نص المشروع العام المفقود إلى خدمة الترجمة الخاصة بـ Google. يتم إعادة استخدام الكتالوجات الموجودة، وحماية أسماء المنتجات، وتطبيق تصحيحات `overrides.json`. بدون `--fetch`، يقوم البرنامج النصي بالإبلاغ عن السلاسل المفقودة ويقوم بتحديث الكتالوجات فقط عندما تكون جميع الترجمات المطلوبة متاحة بالفعل. إنه ليس فحصًا للقراءة فقط.

تظهر بعض العبارات المشتركة أيضًا في كتالوجات كل مشروع. ضع تصحيحات متسقة للصياغة في `overrides.json` وقم بتشغيل البرنامج النصي للإعداد لتطبيقها عبر المشاريع، ثم أعد بناء HTML. قم بمراجعة الترجمات التي تم إنشاؤها قبل النشر. يتم تجاهل المجلد `.translation-cache/` بواسطة Git. لا تستدعي الإصدارات العادية وموقع الويب المنشور خدمة الترجمة مطلقًا.

## الفحوصات قبل النشر

أثناء تشغيل خادم المعاينة المحلي، قم بتشغيل هذه الأوامر في محطة طرفية أخرى:

<div dir="ltr">

```sh
python scripts/build_locales.py --check
python scripts/check_site.py --url http://127.0.0.1:8765
node --test scripts/test_language.cjs
```

</div>

- يكتشف فحص البناء المخرجات التي تم إنشاؤها والتي لا معنى لها والترجمات المفقودة.
- يغطي فحص الموقع جميع صفحات HTML البالغ عددها 261 صفحة: 12 صفحة رئيسية، و240 صفحة مشروع، وثمانية إشعارات للخصوصية، وإعادة توجيه توافقية واحدة. فهو يتحقق من الروابط المحلية والأصول والمعرفات المكررة خارج علامة الخصوصية المحفوظة وبيانات تعريف لغة المشروع وروابط SEO المتبادلة والاتجاه العربي. باستخدام `--url`، فإنه يتحقق أيضًا من استجابات HTTP ويقارن إشعارات الخصوصية المقدمة مع ملفات المصدر الخاصة بها.
- تغطي اختبارات اللغة أسبقية التفضيل، والمطابقة الإقليمية، والتخزين المحظور، وجذور الملفات والدليل الفرعي، وسلوك إعادة التوجيه، والحفاظ على القسم.

للتحقق من الارتباط دون اتصال، قم بتشغيل `python scripts/check_site.py` بدون `--url`. قم بمراجعة الصفحات المتأثرة في المتصفح أيضًا: تخطيط الهاتف المحمول، والاتجاه العربي، وتبديل اللغة، وعناصر تحكم لوحة المفاتيح في المعرض، وتفاعلات المحرر.

## النشر

الموقع المباشر هو [zandaulion.com](https://zandaulion.com/)، المنشور من `main` حتى GitHub Pages. يحتفظ `CNAME` بتكوين المجال المخصص.

بعد إنشاء الموقع والتحقق منه، قم بتنفيذ المصدر والتغييرات التي تم إنشاؤها وادفع `main`. انتظر حتى يكتمل إنشاء **pages build and deployment**، ثم تحقق من عناوين URL التي تم تغييرها في المجال المباشر. احتفظ بمسارات المشروع والخصوصية الحالية عند إعادة تسمية التطبيقات أو مستودعاتها.

يستخدم الموقع الأصول الثابتة والبرامج النصية العادية. يتم تحميل الخطوط من Google Fonts، ويقوم محرر Sankey بتحميل Apache ECharts من jsDelivr. ليست هناك حاجة إلى خدمة الترجمة في وقت التشغيل.
