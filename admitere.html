Admitere Liceu Kit

Explore admission history and simulate high school choices in Bucharest.

Download starter ZIP · 2026-10-21.1 Release notes & SHA-256 View on GitHub

About The Project

Romanian-language guides, synthetic worksheets, historical aggregates and optional Python scripts for organizing high-school admissions choices in Bucharest.

Download and extract the ZIP, then open START.html in your browser. The guides and worksheets need no programming. Keep personal records local; the worksheets are not official application forms.

Gallery

Features

  • 📊 Historical aggregates with clear limits: 405 codes and general cutoffs for 2025, ranking anchors for 2025–2026, incomplete CES aggregates for 2024–2026 and BAC averages/pass rates for 82 schools in 2018–2026. These are historical data, not current application codes.
  • 📋 Synthetic worksheets: CSV templates for choices and deadlines, with fictional examples and source fields.
  • 🎲 Exploratory simulator: A Python model with generated preferences and finite capacity. Model frequencies are not real admission probabilities.
  • 🤖 Family and AI guides: Preparation, comparison and application checks that minimize personal data sharing.
  • 🏫 Checking the 2027 rules: Official source links and a verification checklist. The pack does not certify a final order or reuse an old calendar as current.
  • 🔓 GPL-3.0-or-later: Original code and documentation are free and open source. Third-party source rights remain applicable.

2026-10-21.1 edition limit: the BAC history was rebuilt from public PlusEdu tables, with a source page for each school. It covers only 82 schools and the source can revise its figures. The original PDF and XLSX remain excluded; verify current Ministry and ISMB documents.
