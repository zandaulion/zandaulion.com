About The Project

A full-stack IoT telemetry and control system that logs temperature and heating relay status from Salus iT500 thermostats and Tuya sensors across several properties.

Surfaces operational data three ways: a responsive Progressive Web App with live readings and interactive charts, a Discord bot for fast chat queries, and an automated continuous CSV data store.

Gallery

Features

  • 📱 Live PWA Dashboard: Real-time readings per property, interactive historical charts, and push notifications for temperature thresholds.
  • 🤖 Discord Bot Integration: Query live temperatures with !temp, plot 7-day temperature trends with !plot, and download raw telemetry with !data.
  • 🔥 Visual Heating Overlays: Generates professional charts via matplotlib featuring shaded visual overlays whenever heating relays are active.
  • ⏱️ Automated Background Logging: Records ambient temperature, target setpoints, and relay states every 10 minutes.
  • 🐳 Dockerized & Self-Hosted: Zero-hassle containerized deployment with Docker Compose designed for 24/7 reliability on Raspberry Pi or home servers.
  • 🌍 Timezone Synchronized: Automatic local timezone alignment across all loggers, graphs, and Discord notifications.
