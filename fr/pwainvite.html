PWA Invite Console

Une petite console pour gérer les invitations et les appareils des applications Web privées.

Voir sur GitHub

À propos du projet

Une page pour l'invitation et l'administration des appareils de chaque application derrière le mécanisme d'invitation.

Il s’agit de la seule interface graphique d’administration – les applications en portaient une chacune, ce qui signifiait plusieurs onglets ouverts et plusieurs endroits à mémoriser. Il vit dans son propre référentiel car il n'appartient à aucune des applications qu'il présente.

Tailscale TLS se termine devant l'auditeur privé, limitant l'accès administratif strictement aux nœuds Tailnet autorisés sans point de terminaison public exposé ni mot de passe codé en dur.

Fonctionnalités

  • 🔑 Cycle de vie des invitations unifiées : Générez, partagez, suivez l'expiration et surveillez l'utilisation des liens d'invitation d'applications entre les services à partir d'un seul endroit.
  • 📱 Gestion des appareils : Inspectez les appareils clients inscrits, affichez les derniers horodatages consultés, attribuez des étiquettes conviviales et révoquez instantanément les sessions compromises.
  • 🔒 Sécurité privée Tailnet : Aucune information d'identification stockée dans le code frontal ; authentifié via une injection d'en-tête de proxy inverse privé accessible uniquement via Tailscale.
  • ⚡ PWA à dépendance zéro : Application Vanilla JavaScript monopage avec revalidation immédiate et zéro surcharge du framework.
