Suivez les annonces, comparez les variations de prix et repérez une bonne affaire.

Voir sur GitHub

À propos du projet

Suivez les produits sur OLX.ro et découvrez de véritables bonnes affaires - sur un tableau de bord auto-hébergé et adapté aux mobiles auquel vous pouvez accéder directement depuis votre téléphone.

Il extrait périodiquement des listes pour les recherches configurées, les compare à une base de données SQLite locale pour détecter les nouvelles listes et les baisses de prix, normalise les devises et filtre le bruit et les listes suspectes.

Galerie

Fonctionnalités

  • 🔍 Grattoir et différentiel automatisés : Analyse périodiquement les recherches configurées avec des demandes paginées polies et stocke l'historique complet des prix dans SQLite.
  • 🎯 Notation des transactions et filtrage du bruit : Normalise les devises EUR/RON, filtre les déchets et les accessoires et évalue les listes pour mettre en évidence les offres exceptionnelles.
  • ✨ Valorisation IA avec Gemini Flash : Analyse IA intégrée en un clic évaluant si une annonce est authentique et estimant une valeur marchande réaliste.
  • 📲 Notifications double canal : Les vraies offres arrivent sur votre téléphone via Web Push ; les pannes du système sont signalées silencieusement à un canal NTFY privé.
  • 📱 Tableau de bord mobile auto-hébergé : Un tableau de bord PWA propre et sans dépendance conçu pour une navigation ultra-rapide sur les smartphones.
  • 📦 Quadlet / Podman conteneurisé : Intégration systemd de qualité production avec les unités Quadlet pour une exécution en arrière-plan sans intervention.
