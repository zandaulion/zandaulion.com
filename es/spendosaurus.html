Spendosaurus

Planifica los grandes gastos familiares, desde la primera estimación hasta la última cuota.

Abrir la aplicación web Ver en GitHub

Sobre el proyecto

Una aplicación web progresiva liviana y móvil (PWA) diseñada para que las familias realicen un seguimiento de los gastos importantes, planifiquen estimaciones y agreguen pagos de forma incremental sin fricción y con gestos táctiles intuitivos.

Ya sea renovando una casa, planificando una boda o gestionando una compra familiar importante, Spendosaurus hace que el seguimiento de variaciones sea sencillo a través de señales visuales instantáneas y una ergonomía fluida y móvil.

Galería

Funciones

  • 🪙 Costo incremental añadido: Establezca un presupuesto estimado inicial para un gasto importante y luego registre rápidamente cada cuota o factura parcial a medida que se paga para monitorear las variaciones en tiempo real.
  • 🟢 10% de tolerancia presupuestaria: Los gastos dentro del 10 % del presupuesto estimado se consideran dentro del presupuesto y reciben comentarios ecológicos limpios antes de que se activen las alertas de advertencia.
  • 👆 Gestos de deslizar y tocar: Deslice la tarjeta hacia la derecha para avanzar en el estado del ciclo de vida (Planificado → En curso → Completado), deslícela hacia la izquierda para abrir el historial completo de desgloses y auditorías, o arrastre hacia abajo las hojas modales.
  • 🔙 Navegación trasera sin problemas: Se integra directamente con el historial del navegador API para que los gestos de retroceso de Android e iOS desenrollen las pantallas modales sin problemas.
  • 💱 Soporte de doble moneda: Cambie sin esfuerzo entre RON y EUR con umbrales de alto valor personalizables.
  • 🛡️ Emparejamiento basado en invitaciones: Autenticación de dispositivo perfecta impulsada por el sistema de invitación unificado PWA sin necesidad de contraseñas ni credenciales.
