Sobre el proyecto

Guías en rumano, hojas de trabajo sintéticas, agregados históricos y scripts Python opcionales para organizar las opciones de admisión a la escuela secundaria en Bucarest.

Descargue y extraiga el ZIP, luego abra START.html en tu navegador. Las guías y hojas de trabajo no necesitan programación. Mantenga registros personales locales; Las hojas de trabajo no son formularios de solicitud oficiales.

Galería

Funciones

  • 📊 Agregados históricos con límites claros: 405 códigos y límites generales para 2025, anclajes de clasificación para 2025-2026, agregados CES incompletos para 2024-2026 y promedios/tasas de aprobación de BAC para 82 escuelas en 2018-2026. Estos son datos históricos, no códigos de aplicación actuales.
  • 📋 Hojas de trabajo sintéticas: Plantillas CSV para opciones y plazos, con ejemplos ficticios y campos de origen.
  • 🎲 Simulador exploratorio: Un modelo de Python con preferencias generadas y capacidad finita. Las frecuencias del modelo no son probabilidades de admisión reales.
  • 🤖 Guías familiares y de IA: Preparación, comparación y comprobaciones de aplicaciones que minimicen el intercambio de datos personales.
  • 🏫 Consultando las reglas de 2027: Enlaces de fuentes oficiales y una lista de verificación de verificación. El pack no certifica un pedido final ni reutiliza un calendario antiguo como actual.
  • 🔓GPL-3.0-or-later: El código original y la documentación son gratuitos y de código abierto. Los derechos de fuente de terceros siguen siendo aplicables.

Límite de edición 2026-10-21.1: El historial de BAC se reconstruyó a partir de tablas públicas de PlusEdu, con una página de origen para cada escuela. Cubre sólo 82 escuelas y la fuente puede revisar sus cifras. El PDF y el XLSX originales quedan excluidos; verificar los documentos vigentes del Ministerio y del ISMB.
