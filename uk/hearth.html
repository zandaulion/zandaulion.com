Hearth OCR

Експериментальний інструмент для зчитування фото тонометра у браузері. Кожне значення потрібно звірити самостійно.

Завантажити експериментальний попередній перегляд · 0.1.0 Примітки до випуску та SHA-256 Переглянути на GitHub

Експериментальна версія для браузера

Hearth зчитує систолічний тиск (SYS), діастолічний тиск (DIA) і пульс із фото поширених тонометрів із вертикальним трирядним дисплеєм. Виберіть фото або скористайтеся камерою, обріжте область дисплея й виправте результат перед копіюванням.

Звірте кожне значення з дисплеєм тонометра перед використанням або копіюванням результату. Це експериментальний OCR, а не валідований медичний зчитувач. Точність розпізнавання на нових фотографіях реального світу залишається недоведеною.

Спробуйте попередній перегляд

Завантажте та розпакуйте доданий випуск ZIP. Він включає джерело, дві моделі ONNX і середовище виконання браузера. Не потрібні облікові записи, інсталяції npm або навчання моделі. Рекомендується Python 3.12 або новіша версія.

З витягнутої папки запустіть:

python3 prototype/serve.py

Використовуйте поточний браузер на тому самому комп’ютері, щоб відкрити локальний попередній перегляд:

http://127.0.0.1:8765/

Сервер слухає лише ваш комп’ютер. Для доступу до камери з іншого пристрою потрібен безпечний контекст браузера, наприклад HTTPS.

Як це працює

Детектор знаходить дисплей, а розпізнавач цифр зчитує його рядки. Обчислення ONNX виконуються у worker-потоці браузера. Перевірки узгодженості та нові спроби з іншими обрізаними ділянками можуть відхилити непевний результат або повторити розпізнавання; правильне зчитування не гарантується.

Конфіденційність і використання в автономному режимі

За звичайного використання фото обробляються в пам’яті браузера: застосунок не надсилає їх на сервер і не зберігає. Після першого повного завантаження service worker кешує застосунок і моделі для роботи офлайн. Локальні засоби оцінювання під час розробки становлять окремий процес.

Повторне використання та інтеграція

Оригінальний код і моделі в комплекті використовують AGPL-3.0-only. ONNX Runtime Web зберігає умови MIT. Картка моделі пояснює походження, контрольні суми та обмеження; посібник з інтеграції документує повторне використання в іншій програмі.
