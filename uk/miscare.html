Про проєкт

Почніть з нуля. Рухайтесь у своєму власному темпі. Жодної провини, лише пристосування.

Mișcare — це адаптивний прогресивний веб-додаток (PWA), розроблений для усунення всіх психологічних і фізичних навантажень, пов’язаних із щоденними заняттями фітнесом. Розроблений спеціально для абсолютних новачків або тих, хто повертається після тривалих пауз, Mișcare усуває складні електронні таблиці сетів/повторень, лічильники каральних смуг і страхітливий жаргон у спортзалі.

Відкривши програму, користувачі відразу вітаються повідомленням «Сьогоднішній сеанс» — готові до запуску одним дотиком. Якщо життя насичене, опція «Зробіть це 5 хвилин» одним клацанням миші скорочує тривалість тренування. Якщо життя заважає днями, немає перерваних смуг чи повідомлень провини; програма просто вітає вас назад за допомогою м’якої процедури повторного входу.

Створений на основі Vanilla JavaScript (модулі ES) і Node.js із рідним SQLite, Mișcare інтегрується з Gemini Vision для розпізнавання доступного домашнього обладнання за фотографіями, pwa-kit для нульового простою в автономному кешуванні та плавних оновленнях, а також pwa-invite-console для безпарольного підключення пристрою.

Галерея

Можливості

  • 🌱 Починаючи з нуля: Безпечні базові рухи з вагою тіла (віджимання від стіни, положення сидячи в кріслі, м’яке перемикання сідниць, розтяжка плечей) у поєднанні з теплими ілюстрованими візуальними посібниками та захисними фільтрами для колін, нижньої частини спини та зап’ястя.
  • ⚡ Щоденні сеанси без тертя: На головному екрані миттєво відображається поточна рутина. Включає варіації одним дотиком, наприклад "Зробіть це 5 хвилин" і «Вправа обміну», що супроводжується тихим таймером і звуковим сигналом Web Audio API.
  • 📸 Gemini Розпізнавання апаратури зору: Сфотографуйте предмети домашнього вжитку або тренажери (гантелі, еластичні стрічки, килимки для йоги або міцні стільці). Google Gemini Vision автоматично виявляє предмети та розблоковує відповідні варіанти вправ.
  • 🌿 Адаптивна логіка "No Shaming": Активні дні накопичуються як постійні віхи, а не крихкі смуги. Якщо сеанс оцінюється як «Трохи важкий», наступна програма автоматично зменшує інтенсивність; якщо повертається після перерви, призначається сеанс автоматичної щадної реадаптації.
  • 🔄 Миттєві оновлення через PWA Kit: Інтегровано з pwa-kit для мережевого кешування Service Worker із штампуванням версії хешу вмісту та підказками щодо оновлення без переривання роботи.
  • 🔐 Сполучення пристроїв без пароля: Безпроблемна адаптація через pwa-invite-console коди сполучення (XXXX-YYYY-ZZZZ) випуск захищених, довгострокових маркерів сеансу пристрою.
  • 🎨 Подвійна тема та автономна стійкість: Автоматична світло-темна палітра з лісово-смарагдовими акцентами, повністю функціональна в автономному режимі за підтримки IndexedDB і LocalStorage.

Архітектура та технічний стек

Архітектура фронтенду

Vanilla JavaScript (модулі ES) без накладних витрат на етапи збирання, адаптивні спеціальні властивості CSS, власний синтез веб-аудіо та офлайн-кешування Service Worker.

Backend Engine

Node.js v24 використовує нативний код DatabaseSync від node:sqlite, кінцеві точки Express REST та інтеграція Google Gemini Multimodal Vision API.

Інтеграції

Вбудована сумісність контракту з pwa-kit для керування життєвим циклом версії та pwa-invite-console для активації маркера запрошення та керування пристроєм.
