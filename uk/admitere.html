Досліджуйте історію вступу та моделюйте вибір ліцею в Бухаресті.

Переглянути на GitHub

Про проєкт

Повна методологія, історичні дані, сценарії аналізу та підказки штучного інтелекту для вступу в середню школу та національного оцінювального іспиту в Бухаресті.

Цей пакет містить повний метод для організації вибору вступу до середньої школи, структурований таким чином, що будь-яка сім’я може використовувати його з помічником AI (ChatGPT, Клод, Gemini).

Галерея

Можливості

  • 📊 Історичні дані за три роки: Понад 400 навчальних напрямків із середніми показниками вступу (2024–2026), спеціальними місцями для студентів з особливими освітніми потребами (CES) і прохідними показниками бакалавра (2018–2026).
  • 📈 Криві рейтингу та калібрування: Алгоритми інтерполяції від оцінки до рангу допомагають враховувати щорічні зміни складності іспиту.
  • 🎲 Комп’ютеризований симулятор розміщення: Сценарій Python імітує офіційний алгоритм розміщення ISMB, використовуючи впорядкований список вибору студента.
  • 🤖 Детальний посібник для помічника AI: Структуровані підказки допомагають мовній моделі діяти як спеціальний помічник при вступі.
  • 🏫 Готуємося до реформи 2027 року: Посібник щодо нових вступних іспитів, організованих безпосередньо середніми школами для 50% місць.
  • 🔓 Відкритий код і безкоштовна ліцензія: Безкоштовний і відкритий вихідний код за ліцензією MIT, доступний для кожного батька та вчителя.
