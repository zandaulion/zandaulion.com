About The Project

Art that holds together.

Kerfloom turns photographs and prepared artwork into connected designs for CNC plasma cutting. It brings image treatments, panel layout, supports, manual edits, kerf simulation, an encrypted project workspace, and vector export into one installable web app.

Dark areas represent metal to keep; light areas represent material to remove. The artwork, frame, supports, brush edits, and manufacturing repairs stay separate, so you can revisit a decision without starting over.

A good-looking preview is only the beginning. Kerfloom checks the geometry against a chosen cutting profile, while the operator confirms the settings for the actual material and machine. Profiles stay marked Provisional until verification evidence is recorded.

Application Workflow Gallery

From photograph to cutting file

  1. Prepare: Import an image, compare Original, Tone, and Artwork, then choose a cut style. Tone controls stay available independently of the style. Optional starting dimensions account for the panel size and cutting-profile limits. A quick preview is labelled separately from processed geometry; neither is manufacturing validation.
  2. Panel: Set stock dimensions and orientation, then position, rotate, and scale the artwork. Configure frame and anchor edges and choose the cutting profile used for generation, validation, and export. Artwork fits proportionally without stretching, with unused areas retained as metal.
  3. Support: Find disconnected areas and review suggested bridges before accepting them. Draw supports yourself, use tap-start/tap-end, or adjust their position, angle, and size numerically.
  4. Validate: Choose Run all checks to compare geometry before and after simulated kerf. Inspect individual problems and preview reversible repairs. While fixing a selected issue, use Recheck selected problem to refresh its review without discarding accepted repairs; Escape clears the selection.
  5. Export: Download SVG or DXF when the current cutting geometry is validated. PNG is available as soon as geometry exists, with a visible draft watermark when validation is missing, stale, or blocking. Editable project downloads remain available too. Filenames identify the project, panel size, style, frame choice, purpose, and timestamp.

A pattern with room to experiment

The 14 styles cover Line art, Poster stencil, Icon stencil, Graphic portrait, Silhouette, Negative-space linework, Icon / Woodcut, Flow engraving, Contour bands, Slats, Hatch, Radial cuts, Variable dots, and Ornamental symmetry. Visual swatches and short descriptions help you choose a starting point.

  • Flow engraving: Long, parallel cut ribbons bend around broad tonal forms. Pitch, width, direction, feature following, smoothing, and a dark-area cutoff shape the result while respecting the selected opening and finished-web limits.
  • Radial cuts and Variable dots: Control a solid central hub with rays that split toward the edge, or build a tonal pattern from dots whose circle geometry stays round in SVG and DXF exports.
  • Reviewable smart supports: Filter-aware bridges can favour dark facial features or place sparse slat stabilizers away from a face. Suggestions remain dashed proposals until you accept them.
  • Edits you can revisit: Add, Remove, and Restore are ordered operations in physical panel units. Select an individual stroke or region to move, resize, hide, change, or delete it without undoing later work. Painting updates immediately and marks previous validation stale, so the next gesture does not wait for a full-panel scan.

Checks that travel with the project

A versioned cutting profile records the process, stock, machine or consumable, geometry limits, support assumptions, and verification evidence. Projects and retained exports keep their own snapshot, so the settings behind a result remain identifiable.

Kerf simulation and repair previews test the configured geometry limits. Repair reports explain what changed, the remaining uncertainty, why an attempt stopped, and what to try next. Validation, repairs, and smart-support planning show progress and can be cancelled while the last accepted geometry remains usable.

Accepted repairs remain active during manual material and support corrections. A painted area overrides only an opposing generated edit in that area. Run all checks when you are ready for the next complete validation; changing the underlying artwork, panel geometry, or cutting limits makes dependent repairs stale and requires regeneration.

Retained exports include a tamper-evident release manifest with geometry and output hashes, units, profile settings, the compensation contract, and validation evidence. Optional vector simplification is accepted only when topology and manufacturing checks pass; otherwise the export falls back to the exact raster contours.

Ready for CAM review means the current geometry passed Kerfloom's configured checks. The operator still verifies the material, machine, consumables, compensation, lead-ins, cut order, fixturing, heat behaviour, and final use. New projects export intended finished-part boundaries, with inside/outside kerf compensation applied exactly once in CAM.

The General plasma profile starts with a 2 mm minimum opening and a conservative 3 mm finished gap/web. Lower limits need confirmation for the selected stock and machine. Profiles remain Provisional until verification evidence is recorded.

Keep working, across devices

  • Start with a local draft: New project creates one recoverable draft on your device. Import and experiment, then choose Save to Projects to add it to the encrypted workspace. Starting another project warns before replacing an unsaved draft.
  • Autosave and recovery: Workspace project edits save locally first and queue for synchronization. The app reports a server save only after acknowledgement. Source images and exports upload once; ordinary edits send smaller state updates. Up to ten recovery points, recoverable Trash, and conflict copies help protect ongoing work.
  • A library that opens from your cache: Browse and search projects without downloading the whole workspace. Choose Save offline to retain a complete project and its source and exports on a device.
  • Link your devices: A one-time QR code or private link connects another device to the same live workspace. Linked devices can be reviewed and revoked.
  • Share an independent copy: An encrypted snapshot can be claimed by one recipient on an invited Kerfloom device. Links expire after 7, 30, or 90 days and can be revoked. Sharing does not give the recipient access to your live workspace; revocation cannot erase an already imported copy.
  • Portable projects: Editable .stencil.json downloads omit the original photograph. Encrypted workspace and share packages can include it when available, alongside edits, supports, repairs, recovery points, and retained exports.

Install it and take projects offline

On Windows, use the install icon or Apps / Install menu in Edge or Chrome. On Android, choose Install app or Add to Home screen in Chrome. On iPhone or iPad, open the app in Safari and choose Share, then Add to Home Screen.

Load the app on an authorised device while online, and open a server-only project or choose Save offline before disconnecting. Cached projects stay editable and changes queue until synchronization succeeds; photographic processing still needs a connection. After an app update, open the installed copy online so it can refresh.

At a desk, or beside the cutting table

On mobile, the canvas stays in view while stage controls open in compact bottom sheets. A persistent tool rail keeps projects, sync state, Undo/Redo, and editing tools accessible. Rulers keep physical units as you zoom, with a visible red scale indicator over metal and openings. Supports have keyboard, list, numeric, and tap-based alternatives, and Pan mode keeps navigation separate from editing.

The interface includes visible focus, keyboard navigation for workflow tabs, and screen-reader notices. Physical-device and assistive-technology acceptance checks remain in progress.

Select Help in the app for its searchable handbook, or open a stage's question-mark button at the relevant chapter. You can also read the user guide on GitHub.

Behind the scenes

The browser handles line-art conversion, deterministic geometry, editing, and the offline cache. A Node/Express service manages invite-based device access and encrypted workspaces; a private Python/FastAPI service uses OpenCV and MediaPipe for photographic analysis and style rendering.
