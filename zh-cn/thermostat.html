Thermostat Monitor

通过传感器历史记录和温度图表，了解家里的冷暖。

在 GitHub 上查看

关于项目

全栈物联网遥测和控制系统，可记录来自多个物业的 Salus iT500 恒温器和 Tuya 传感器的温度和加热继电器状态。

通过三种方式显示运营数据：具有实时读数和交互式图表的响应式渐进式 Web 应用程序、用于快速聊天查询的 Discord 机器人以及自动连续 CSV 数据存储。

图片集

功能

  • 📱 实时 PWA 仪表板： 每个属性的实时读数、交互式历史图表以及温度阈值的推送通知。
  • 🤖 Discord 机器人集成： 查询实时温度 !temp，绘制 7 天温度趋势 !plot，并下载原始遥测数据 !data.
  • 🔥 视觉加热覆盖： 当加热继电器处于活动状态时，通过 matplotlib 生成专业图表，具有阴影视觉叠加层。
  • ⏱️ 自动后台日志记录： 每 10 分钟记录一次环境温度、目标设定点和继电器状态。
  • 🐳 Docker 化和自托管： 使用 Docker Compose 进行零麻烦的容器化部署，专为 Raspberry Pi 或家庭服务器上的 24/7 可靠性而设计。
  • 🌍 时区同步： 所有记录器、图表和 Discord 通知的本地时区自动对齐。
