Threadmark

把热闹的 WhatsApp 群聊变成一份需要你处理的简短清单：付款、会议和截止日期。

在 GitHub 上查看

Threadmark 需要自行托管：每个人运行自己的私有副本。

关于该应用程序

Threadmark 是一个私密的注意力收件箱，面向你选定的 WhatsApp 群组和联系人。新消息一到它就会读取，挑出付款、会议、截止日期以及你让它留意的其他内容，并且只显示这些。其余内容都留在 WhatsApp 里。

它像 WhatsApp Web 一样以关联设备的身份连接，并且在设计上只读：从不发送消息，从不把聊天标为已读，从不显示你在线，也从不读取旧的聊天记录。这种连接并非官方方式，WhatsApp 可能会改变它，或限制使用它的账号。

每个群组和联系人在你开启之前都处于关闭状态。其他聊天的消息会在检查或存储之前被丢弃，选定聊天中没有匹配任何内容的消息也不会保留。

它是如何运作的

  1. 连接 WhatsApp。 用二维码或配对码把 Threadmark 关联为设备。
  2. 选择聊天。 只开启需要关注的群组和联系人。可以按名称或号码搜索，也可以从手机导入联系人。
  3. 让它来筛选。 内置检测器和你自己的短语规则会在服务器上检查每条新消息。如果都没有匹配且开启了 Jev，AI 服务会再看一遍。
  4. 处理要紧的事。 可以把事项标记为完成、稍后提醒、添加到日历，或在 Threadmark 判断错误时告诉它。

功能

  • 在本地识别付款和会议： 内置检测器读取罗马尼亚语和英语消息，提取金额、币种、IBAN、日期、时间和链接。
  • 你自己的规则： 短语规则会查找你指定的任一或全部词语，不区分大小写和重音符号，并且从不离开服务器。每条规则都可以限定在部分聊天，选择是否提醒，并先用示例测试。
  • 用日常语言写的监控： 用一句话描述要留意的内容，比如需要处理的包裹或预订，并设置 Jev 要有多大把握才标记一条消息。
  • AI 仅作后备： 本地没有匹配时，TypeSafe AI 提供的可选服务 Jev 会查找付款、会议和提醒，并评估紧急程度。它只会收到消息正文，绝不会收到聊天名称、发送者、电话号码或 WhatsApp ID。
  • 截止日期和紧急程度： 会从消息中读取到期日期，事项会显示即将到期和已逾期标记，紧急事项排在最前。
  • 付款警示： 银行信息变更、金额变动、可能的重复以及索要密码或付款的异常请求，都会被标出，提醒你再核实一次。
  • 附件也在本地读取： 照片、PDF 和语音消息可以在服务器上通过文字识别和语音转写读取，随后立即删除。无法识别的手写便条会变成一条提醒，让你查看原照片。
  • 变更与回复： Threadmark 可以发现计划被更正或取消，并在你回复后关闭回复提醒。两项功能默认关闭，最多只保留 48 小时的近期文本。
  • 提醒和每日摘要： 新事项会推送通知，紧急事项会使用紧急标题，还可以在你选定的时间收到每日摘要。
  • 只短暂保留： 识别出的摘录默认在 30 天后删除，除非对应事项仍未处理。

在引擎盖下

Threadmark 由两部分组成，各自运行在独立的无 root 权限 Podman 容器中。桥接服务通过 Baileys 库保持与 WhatsApp 的连接，并把每条消息保存在队列中，直到应用收到为止。应用运行在 Node.js 24 及其内置 SQLite 上，通过 server-sent events 和 Web Push 向浏览器实时推送更新。桥接服务不对外开放任何端口。访问需要邀请，邀请由 PWA Invite Console 管理，应用通过 pwa-kit 自动更新。消息以中立格式传给应用，因此以后可以接入 Telegram 或电子邮件等其他来源。该项目以 GPL-3.0 许可证开源。
