关于项目

从零开始。按照自己的步调移动。没有愧疚，只是调整。

Mișcare 是一款自适应渐进式 Web 应用程序 (PWA)，旨在消除与日常健身相关的每一层心理和身体摩擦。 Mișcare 专为绝对初学者或长时间休息后返回的个人而设计，消除了复杂的组/次数电子表格、惩罚性连胜计数器和令人生畏的健身术语。

打开应用程序后，用户会直接看到“今天的会话”——只需轻按一下即可启动。如果生活变得忙碌，一键“Make it 5 分钟”选项可以缩短锻炼时间。如果生活连续几天受到阻碍，也不会出现中断的情况或内疚的信息；该应用程序只是以温和的重新进入程序欢迎您回来。

Mișcare 采用 Vanilla JavaScript（ES 模块）和 Node.js 以及本机 SQLite 构建，与 Gemini Vision 集成，可从照片中识别可用的家用设备，pwa-kit 可实现零停机离线缓存和无缝更新，并与 pwa-invite-console 集成，可实现无密码设备登录。

功能

  • 🌱从零开始： 安全、基础的体重运动（靠墙俯卧撑、椅子坐站、温和的臀桥、肩部活动伸展）搭配温暖的插图视觉指南和针对膝盖、下背部和手腕的保护过滤器。
  • ⚡ 零摩擦每日课程： 主屏幕立即满足今天的日常需求。包括一键变体，例如 “5分钟” 和 《交换练习》，伴随着安静的计时器和网络音频 API 铃声。
  • 📸 Gemini 视觉设备识别： 拍摄家居用品或健身器材（哑铃、阻力带、瑜伽垫或坚固的椅子）的照片。 Google Gemini Vision 自动检测项目并解锁匹配的练习变体。
  • 🌿“不羞辱”自适应逻辑： 活跃天数是作为永久的里程碑累积起来的，而不是脆弱的连续记录。如果某次训练被评为“有点困难”，则下一次训练会自动降低强度；如果休息后返回，则会安排自动温和的重新适应课程。
  • 🔄 通过 PWA Kit 即时更新： 集成于 pwa-kit 用于网络优先的 Service Worker 缓存，具有内容哈希版本标记和无中断更新提示。
  • 🔐 无密码设备配对： 无缝入职通过 pwa-invite-console 配对码（XXXX-YYYY-ZZZZ）发出安全、长期的设备会话令牌。
  • 🎨 双主题和离线弹性： 自动明/暗调色板，带有森林翡翠色调，功能齐全的离线功能，由 IndexedDB 和 LocalStorage 支持。

架构与技术堆栈

前端架构

Vanilla JavaScript（ES 模块），无需构建步骤开销、响应式 CSS 自定义属性、自定义 Web 音频合成和 Service Worker 离线缓存。

后端引擎

Node.js v24 利用原生 DatabaseSync 来自 node:sqlite、Express REST 端点和 Google Gemini Multimodal Vision API 集成。

集成

与用于版本生命周期管理的 pwa-kit 和用于邀请令牌兑换和设备管理的 pwa-invite-console 的本机合约兼容性。
