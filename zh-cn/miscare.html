Android 应用

Mișcare 已在 Google Play 上架，支持 Android 7.0 或更高版本，自 0.1.1 版（2026 年 11 月 3 日）起正式发布。它包含引导训练、45 个带插图的动作、12 种界面语言、浅色或深色主题，以及可用 JSON 备份的本地训练日志。无需账号、服务器或联网权限。

0.1.1 版让每个界面都以你选择的语言显示，保持类动作按秒数而不是次数计算，并且即使只用自身体重，“从零开始”也会保持在你的级别。它还新增了深色主题，预计时长现在会随你选择的组数变化。

如果想手动安装，请从 GitHub Releases下载已签名的 APK。它的签名与 Play 版本不同，因此两者不能互相更新：切换前请先导出数据。Android 应用不会导入 PWA 的历史记录，JSON 导入会替换当前的个人资料和日志。校验和、签名及尚待完成的检查请参阅 安装与备份指南 了解详情。尚未实现提醒功能。

关于项目

从零开始。按照自己的步调移动。没有愧疚，只是调整。

Mișcare 是一款自适应运动应用，既有 Google Play 上的 Android 应用，也有可自行托管的网页版。它为初学者和中断一段时间后重新开始的人设计，提供简短的训练、器材选择和日志。是否进阶由你决定，休息日也不会因为中断连续记录而受罚。

打开应用程序后，用户会直接看到“今天的会话”——只需轻按一下即可启动。如果生活变得忙碌，一键“Make it 5 分钟”选项可以缩短锻炼时间。如果生活连续几天受到阻碍，也不会出现中断的情况或内疚的信息；该应用程序只是以温和的重新进入程序欢迎您回来。

自行托管的 PWA 使用 Vanilla JavaScript、Node.js 和 SQLite，支持 pwa-kit 更新和 pwa-invite-console 设备邀请。Android 应用将界面和自适应引擎打包在 Capacitor 中，把个人资料和日志保存在本机的 IndexedDB 里，并通过 Google Play 或安装更新的已签名 APK 来更新。

功能

  • 🌱从零开始： 基础自重动作（扶墙俯卧撑、从椅子上起立、温和臀桥、肩部活动度拉伸），配有 12 种语言的插图指南，以及保护膝盖、下背部和手腕的筛选。
  • ⚡ 零摩擦每日课程： 主屏幕立即满足今天的日常需求。包括一键变体，例如 “改成5分钟” 和 “换一个动作”，配有低调的计时器和通过 Web Audio API 播放的柔和提示音。可选择 1、2 或 3 组，预计时长会随之调整。
  • 🔁 轮换的训练： 每完成一次训练，轮换就前进一步，因此你会依次做到所有适合你的动作；跳过的一天会把错过的训练还给你。动作模式（推、拉、深蹲、髋部、核心、小腿、负重行走）也会交替，所以没有哪一组会出现在每次训练中。保持类动作按秒计算。
  • 设备过滤器： 选择您拥有的设备和您想要保护的区域；例程会适应这些选择。
  • 🌿“不羞辱”自适应逻辑： 活跃日会累积为永久的成就，而不是容易中断的连续记录。如果某次训练被评为“有点吃力”，下一次训练会自动降低强度；如果你在 4 天或更久之后回来，会自动安排一次温和的恢复训练。
  • 🔄PWA 更新： 集成于 pwa-kit 用于网络优先的 Service Worker 缓存，具有内容哈希版本标记和无中断更新提示。
  • 🔐 PWA 设备配对： 无缝入职通过 pwa-invite-console 配对码（XXXX-YYYY-ZZZZ）发出安全、长期的设备会话令牌。
  • 🎨 浅色或深色主题与离线使用： 跟随手机主题，或在设置中选择，带有翡翠绿点缀；借助 IndexedDB 和 LocalStorage，可完全离线使用。

架构与技术堆栈

前端架构

Vanilla JavaScript（ES 模块），无需构建步骤开销、响应式 CSS 自定义属性、自定义 Web 音频合成和 Service Worker 离线缓存。

后端引擎

PWA 使用 Node.js 24、其内置的 node:sqlite以及 Express REST 接口。Android 版在本地运行共用的训练引擎，无需后端。

集成

与用于版本生命周期管理的 pwa-kit 和用于邀请令牌兑换和设备管理的 pwa-invite-console 的本机合约兼容性。
