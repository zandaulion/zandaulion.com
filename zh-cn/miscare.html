安卓预览版

Mișcare 0.1.0 是适用于 Android 7.0 或更高版本的抢先体验 Android 下载。它捆绑了指导性例程、45 个图解练习、12 种界面语言和本地锻炼日志。不需要帐户、服务器或互联网权限。

Android 应用程序以单独的本地数据启动；它不会自动导入 PWA 历史记录。 JSON 导入替换当前配置文件和日志。请参阅 安装与备份指南 用于校验和、签名兼容性和剩余验证。提醒未实施。

关于项目

从零开始。按照自己的步调移动。没有愧疚，只是调整。

Mișcare 是一款自适应锻炼应用，提供本地 Android 版和可自行托管的网页版。它为初学者和暂停锻炼后重新开始的人提供短时训练、器材选择和锻炼日志。是否进阶由你决定，休息日不会因打断连续锻炼记录而受到惩罚。

打开应用程序后，用户会直接看到“今天的会话”——只需轻按一下即可启动。如果生活变得忙碌，一键“Make it 5 分钟”选项可以缩短锻炼时间。如果生活连续几天受到阻碍，也不会出现中断的情况或内疚的信息；该应用程序只是以温和的重新进入程序欢迎您回来。

自托管 PWA 使用 Vanilla JavaScript、Node.js 和 SQLite，并具有 pwa-kit 更新和 pwa-invite-console 设备邀请。 Android 应用程序将界面和自适应引擎捆绑在 Capacitor 中，将其配置文件和日志本地存储在 IndexedDB 中，并通过 APK 安装接收可执行更新。

功能

  • 🌱从零开始： 基础自重运动（靠墙俯卧撑、椅子坐站、轻柔臀桥、肩部活动伸展）搭配温暖的插图视觉指南和针对膝盖、下背部和手腕的保护过滤器。
  • ⚡ 零摩擦每日课程： 主屏幕立即满足今天的日常需求。包括一键变体，例如 “5分钟” 和 《交换练习》，伴随着安静的计时器和网络音频 API 铃声。
  • 设备过滤器： 选择您拥有的设备和您想要保护的区域；例程会适应这些选择。
  • 🌿“不羞辱”自适应逻辑： 活跃天数是作为永久的里程碑累积起来的，而不是脆弱的连续记录。如果某次训练被评为“有点困难”，则下一次训练会自动降低强度；如果休息后返回，则会安排自动温和的重新适应课程。
  • 🔄PWA 更新： 集成于 pwa-kit 用于网络优先的 Service Worker 缓存，具有内容哈希版本标记和无中断更新提示。
  • 🔐 PWA 设备配对： 无缝入职通过 pwa-invite-console 配对码（XXXX-YYYY-ZZZZ）发出安全、长期的设备会话令牌。
  • 🎨 双主题和离线弹性： 自动明/暗调色板，带有森林翡翠色调，功能齐全的离线功能，由 IndexedDB 和 LocalStorage 支持。

架构与技术堆栈

前端架构

Vanilla JavaScript（ES 模块），无需构建步骤开销、响应式 CSS 自定义属性、自定义 Web 音频合成和 Service Worker 离线缓存。

后端引擎

PWA 使用 Node.js 24、其内置的 node:sqlite以及 Express REST 接口。Android 版在本地运行共用的训练引擎，无需后端。

集成

与用于版本生命周期管理的 pwa-kit 和用于邀请令牌兑换和设备管理的 pwa-invite-console 的本机合约兼容性。
