Spendosaurus

规划家庭的大额开支，从初次估算到最后一期付款。

打开网页应用 在 GitHub 上查看

关于项目

一款轻量级、移动优先的渐进式 Web 应用程序 (PWA)，专为家庭设计，用于跟踪大额支出、计划估算并通过零摩擦和直观的触摸手势逐步增加付款。

无论是装修房屋、筹划婚礼，还是管理家庭大额采购，Spendosaurus 都可以通过即时视觉提示和流畅的移动优先人体工程学设计，让差异跟踪变得毫不费力。

功能

  • 🪙 增量成本附加： 为主要费用设置初​​始估计预算，然后快速记录每笔分期付款或部分账单，以实时监控差异。
  • 🟢 10% 预算容差： 预计预算 10% 以内的费用被视为在预算范围内，并在警告警报触发之前提供干净的绿色反馈。
  • 👆 滑动和触摸手势： 向右刷卡可推进生命周期状态（已计划 → 进行中 → 已完成），向左刷卡可打开完整的故障和审核历史记录，或向下拖动模式表。
  • 🔙 无缝边缘返回导航： 直接与浏览器历史记录 API 集成，因此 Android 和 iOS 边缘返回手势可无缝展开模态屏幕。
  • 💱 双币支持： 通过可定制的大额门槛，轻松在 RON 和 EUR 之间切换。
  • 🛡️ 基于邀请的配对： 由统一的 PWA 邀请系统提供支持的无缝设备身份验证，无需任何密码或凭据。
