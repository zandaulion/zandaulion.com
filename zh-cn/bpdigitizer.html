一份血压日志，采用 Android 和 Web 形式。记录您的读数、探索趋势并导出您的历史记录。

一个应用程序。有两种使用方法。

BP Digitizer 帮助你记录血压读数、查看历史并保存自己的记录。你可以使用原生 Android 应用，也可以在浏览器中打开 PWA。两者都能在你自己的设备上用摄像头读取血压计，也都不需要账号。网页版此前在这里以 wBP Digitizer 的名称列出，它是同一项目的一部分。

BP Digitizer 网页版

PWA 把同一项目带到浏览器中，提供摄像头扫描、手动录入、图表和导出。读数保存在浏览器的 IndexedDB 中，应用由 GitHub Pages 提供，背后没有服务器、账号或邀请。把它安装到主屏幕，随时取用。

在网络应用程序内部

网页功能

  • 📱 本地优先 & PWA： 安装到主屏幕并离线工作。读数存在于浏览器的 IndexedDB 中，并且永远不会发送到任何地方。
  • 📷 在设备上用摄像头读取： 把摄像头对准显示三行数字的竖式血压计，在浏览器中运行的模型会读取 SYS、DIA 和脉搏。保存前你需要确认全部三个数值，无法可靠读取的照片会被拒绝，而不是靠猜测。
  • ✏️快速进入： 从上次读数开始的滑块、数字框，以及长按快速调整。
  • 📈综合图表： 趋势图（收缩压 + 舒张压，120/80 参考线）和收缩压与舒张压散点图。 7 / 30 / 90 天和所有时间范围。
  • 🧠 智能分析： 突发平均将连续读取的读数压缩为一个点。在设备上计算的见解（早上与晚上、范围内的时间、健康的条纹、上下文标签）。
  • 🩺 临床逻辑： AHA 分区(正常 / 偏高 / 1 期 / 2 期 / 危象)、平均动脉压和脉压、BMI，以及基于健康档案的风险评估。
  • 📄 导出和报告： CSV 和 JSON 导入与导出，以及可打印、可下载的 PDF 报告。
  • 🔐 加密备份： 把读数和健康档案备份到用你的口令加密的文件中，并在另一台设备上恢复。丢失的口令任何人都无法找回。
  • 🌐 全球： 12 种语言直接沿用 Android 应用的翻译，而非重新翻译，并支持阿拉伯语从右到左显示。

BP Digitizer 适用于 Android

原生 Android 应用完全在手机上用摄像头读取血压计，还提供快速手动录入、趋势视图、Health Connect、PDF 导出和提醒。它没有联网权限，Android 的云备份和手机间迁移对它也已关闭，因此除非你导出，读数只会留在手机上。它可在 Android 8.0 及以上的 ARM64 手机上运行。

Android 应用程序内部

截取自 1.6.2 版。所有读数和档案数值都是虚构的。

安卓功能

  • 🏃 专为积极的生活方式而打造： 血压是一项核心健康指标，与步数、锻炼和睡眠一样。只需几秒钟即可记录下来，并将其作为让您不断前进的日常活动的一部分。
  • ✏️ 在几秒钟内免费记录您的读数： 快速、易于点击的滑块可让您立即设置收缩压、舒张压和脉搏。完全免费，离线工作，无需帐户 - 从您第一次打开应用程序时开始跟踪。
  • 📷 或离线用摄像头扫描： 不想手动输入？拍下血压计的屏幕，应用内置的模型就会在手机上读取数值，无需联网。这项功能免费，保存前你始终会核对数值。
  • 📈 观察你的趋势： 查看您的数字在几天、几周和几个月内的变化情况。在趋势线和 3D 散点图之间切换，您可以用手指旋转来一起探索收缩压、舒张压和脉搏。智能“平均”平滑将背靠背读数合并为单个、诚实的数据点，因此您的趋势反映了现实。把手机横过来，即可并排查看两张图表。
  • 🏷️ 看看是什么改变了你的数字： 给任何阅读的内容加上背景信息——锻炼、咖啡因、咸食、睡眠质量差、压力——并发现你的活动和生活方式如何随着时间的推移影响你的数字。
  • ❤️ 与 Health Connect 连接： 从仪表盘把读数复制到 Android Health Connect，让血压与你的活动、锻炼和其他健身数据放在一起。这是可选功能，只在你选择时进行。
  • 📄 保留自己的记录： 导出 JSON 备份、CSV 文件或包含图表和读数的多页 PDF 报告，并可导入本应用或网页版的备份。
  • ⏰ 养成一致的习惯： 可选的温和提醒可帮助您每天早晚同时记录，让您的趋势保持完整。
  • 🔒 设计上的私密性： 应用完全没有联网权限。无需创建账号，无需注册云服务，也不会出售或分享任何数据。要保留副本或换新手机，请导出 JSON 备份。你的数字只属于你自己。
  • 🌐 12 种语言： 英语、阿拉伯语、中文、法语、德语、印地语、日语、韩语、葡萄牙语、罗马尼亚语、西班牙语和乌克兰语。
