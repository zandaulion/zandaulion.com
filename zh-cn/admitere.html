Admitere Liceu Kit

查看历年录取情况，模拟布加勒斯特的高中志愿选择。

下载入门套件 ZIP · 2026-10-21.1 发行说明和 SHA-256 在 GitHub 上查看

关于项目

用于整理布加勒斯特高中报考志愿的罗马尼亚语指南、虚构数据工作表、历史汇总数据和可选 Python 脚本。

下载并解压 ZIP，然后在浏览器中打开 START.html 。指南和工作表无需编程知识。请将个人记录保留在本地；这些工作表不是官方报名表。

图片集

功能

  • 📊 适用范围明确的历史汇总数据： 包含 2025 年的 405 个专业代码和普通录取分数线、2025–2026 年的排名参考点、2024–2026 年不完整的 CES 汇总数据，以及 82 所学校在 2018–2026 年的 BAC 平均成绩和通过率。这些是历史数据，不是当年的报考代码。
  • 📋 虚构数据工作表： CSV 用于选择和截止日期的模板，带有虚构的示例和源字段。
  • 🎲 探索模拟器： 具有生成偏好和有限容量的 Python 模型。模型频率并不是真实的录取概率。
  • 🤖 家庭和人工智能指南： 准备、比较和检查报考材料，同时尽量减少个人数据的分享。
  • 🏫 检查 2027 年规则： 提供官方来源链接和核查清单。套件不确认最终的部长令是否已颁布，也不会把旧日程当作现行日程。
  • 🔓GPL-3.0-or-later： 原始代码和文档是免费且开源的。第三方来源权利仍然适用。

2026-10-21.1版本限制： BAC 历史记录是根据公共 PlusEdu 表重建的，每个学校都有一个源页面。它仅涵盖 82 所学校，消息来源可以修改其数字。原始 PDF 和 XLSX 仍被排除；核实当前的部委和 ISMB 文件。
