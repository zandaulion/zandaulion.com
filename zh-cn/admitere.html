查看历年录取情况，模拟布加勒斯特的高中志愿选择。

下载启动器 ZIP · 2026-10-21.1 发行说明和 SHA-256 在 GitHub 上查看

关于项目

罗马尼亚语指南、综合工作表、历史汇总和可选的 Python 脚本，用于组织布加勒斯特的高中招生选择。

下载并解压ZIP，然后打开 START.html 在您的浏览器中。指南和工作表不需要编程。将个人记录保存在本地；这些工作表不是正式的申请表。

图片集

功能

  • 📊 有明确限制的历史总量： 2025 年的 405 代码和一般截止点、2025-2026 年的锚定排名、2024-2026 年不完整的 CES 汇总以及 2018-2026 年 82 所学校的 BAC 平均/通过率。这些是历史数据，而不是当前的应用程序代码。
  • 📋 综合工作表： CSV 用于选择和截止日期的模板，带有虚构的示例和源字段。
  • 🎲 探索模拟器： 具有生成偏好和有限容量的 Python 模型。模型频率并不是真实的录取概率。
  • 🤖 家庭和人工智能指南： 准备、比较和应用检查，最大限度地减少个人数据共享。
  • 🏫 检查 2027 年规则： 官方来源链接和验证清单。该包不证明最终订单或将旧日历重新用作当前日历。
  • 🔓GPL-3.0-or-later： 原始代码和文档是免费且开源的。第三方来源权利仍然适用。

2026-10-21.1版本限制： BAC 历史记录是根据公共 PlusEdu 表重建的，每个学校都有一个源页面。它仅涵盖 82 所学校，消息来源可以修改其数字。原始 PDF 和 XLSX 仍被排除；核实当前的部委和 ISMB 文件。
