Faceslice

一张照片变成三维浮雕，再切分成多层，组成金属人像。

打开网页应用 在 GitHub 上查看

关于项目

从正面照片生成分层肖像的切割图案，将金属薄板逐层手工粘合，组成宛如地形图的浮雕。

Faceslice 将标准 2D 自拍照转换为由激光切割金属板或卡片纸制成的物理分层地形雕塑。 Faceslice 不需要复杂的多相机摄影测量或挑剔的 3D 扫描应用程序，只需一张正面照片和以毫米为单位的瞳距 (IPD) 测量值即可确定物理比例。

为了从一张照片中重建真实的头部，Faceslice 精心策划了一个三模型计算机视觉融合管道，其中每个模型都贡献其最擅长的功能：轮廓分割捕捉头发、耳朵和下巴轮廓；单眼深度估计广泛的颅骨体积；面部网格标志模型提取清晰的面部标志（鼻子、眼窝、嘴唇）作为残余表面位移。

生成的 3D 实体以自定义角度切成平行平面。正面切片可产生自对准嵌套轮廓等高面，每块板上均配有蚀刻对准导轨，镂空隐藏内部可减轻高达 80% 的重量，并可即时输出生产级 DXF。

功能

  • 📸 单照片 3D 重建： 将单张正面自拍照转换为完整的深度立体图，并使用瞳孔距离校准到真实世界的尺寸。
  • 🧠 3模型AI融合引擎： 结合 MediaPipe 多类分割、ONNX 单眼深度估计 (Depth Anything V2) 和 MediaPipe 面部标志器，以平衡头骨体积和面部清晰度。
  • 🗺️地形轮廓切片： 将实体切成具有自由角度控制的平行平面（正面用于同心嵌套等高面，水平用于侧面剖面叠层）。
  • 🎯 自对准装配指南： 当正面切片时，每个金属层都嵌套在下面的金属层内，并且下一块金属板的边界线直接雕刻在其表面上，以便无需夹具即可轻松对齐。
  • ♻️ 内部镂空&材料经济： 自动去除隐藏的内部几何形状，减少材料消耗和重量高达 80%（例如，10 公斤实心钢减少到 1.9 公斤空心环），同时保持坚固的粘合边缘。
  • ⚙️ 参数化制造控制： 板材厚度（0.5-10 毫米）、浮雕压缩、切口补偿、面部浮雕夸张和切片角度的实时交互式调整。
  • ⚖️ 实时材料和重量估算器： 动态计算钢、黄铜和铝的板数、独特轮廓、所需的钣金面积 (dm²)、堆叠高度和精确质量。
  • 📐 生产就绪 DXF 导出： 只需单击一下即可导出完全矢量化、激光/水射流/等离子 CAM 就绪的 DXF 文件，嵌套到自定义板材尺寸。

架构与技术堆栈

交互式网络客户端

Vanilla JavaScript（ES 模块）、响应式画布和 SVG 轮廓渲染、实时参数滑块以及支持离线的 PWA 架构。

视觉与几何引擎

Python 3 计算核心利用 MediaPipe（分割和面网格）、ONNX 运行时（Depth Anything V2 Small）、用于 2D 多边形布尔运算和镂空的 Shapely 以及用于 CAD 生成的 ezdxf。

生产部署

使用 Podman 和 systemd Quadlet 进行容器化，通过自动化资产哈希版本标记 deploy.sh，并通过 Caddy 反向代理提供服务，CPU 上的切片响应时间为亚秒级。
