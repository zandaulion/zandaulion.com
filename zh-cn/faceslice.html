Faceslice

一张照片变成三维浮雕，再切分成多层，组成金属人像。

打开网页应用 在 GitHub 上查看 下载源代码包

关于项目

从正面照片生成分层肖像的切割图案，将金属薄板逐层手工粘合，组成宛如地形图的浮雕。

Faceslice 将正面照片转换为金属片或卡片纸上分层浮雕的切割图案。输入以毫米为单位的瞳距 (IPD) 以设置比例。结果是头部可见侧的浮雕，而不是整个头部的扫描。

Faceslice 结合三种计算机视觉模型估计浮雕形状：分割模型提取剪影，单目深度估计整体形体，面部关键点补充鼻子、眼睛和嘴唇周围的细节。几何形状只是基于单张图像的估计。

浮雕以可调角度切成平行平面。正面切片相互嵌套，并带有雕刻的对齐指南。该工具可以去除隐藏的内部材料并导出 DXF 切割片。制造前与车间检查尺寸和切割设置。

功能

  • 📸 单张照片生成浮雕： 将一张正面照片转换为分层浮雕，并使用您提供的瞳孔距离测量值进行缩放。
  • 🧠 3模型AI融合引擎： 结合 MediaPipe 多类分割、ONNX 单眼深度估计 (Depth Anything V2) 和 MediaPipe 面部标志器，以平衡头骨体积和面部清晰度。
  • 🗺️地形轮廓切片： 将实体切成具有自由角度控制的平行平面（正面用于同心嵌套等高面，水平用于侧面剖面叠层）。
  • 🎯 自对准装配指南： 当正面切片时，每个金属层都嵌套在下面的金属层内，并且下一块金属板的边界线直接雕刻在其表面上，以便无需夹具即可轻松对齐。
  • ♻️ 内部镂空&材料经济： 自动去除隐藏的内部几何形状，减少材料消耗和重量高达 80%（例如，10 公斤实心钢减少到 1.9 公斤空心环），同时保持坚固的粘合边缘。
  • ⚙️ 参数化制造控制： 板材厚度（0.5-10 毫米）、浮雕压缩、切口补偿、面部浮雕夸张和切片角度的实时交互式调整。
  • ⚖️ 材料和重量估计： 显示钢、黄铜和铝的板数、轮廓、板材面积、堆叠高度和估计重量。
  • 📐 DXF 导出： 导出与所选板材尺寸相符的矢量切割图。切割前请与加工方核对。

架构与技术堆栈

交互式网络客户端

Vanilla JavaScript（ES 模块）、响应式画布和 SVG 轮廓渲染、实时参数滑块以及支持离线的 PWA 架构。

视觉与几何引擎

Python 3 引擎使用 MediaPipe、ONNX Runtime、NumPy、SciPy 和 OpenCV。自有几何与 DXF 模块负责生成分层和切割图。

部署注意事项

源代码包括 Podman 容器配方和本地运行说明。 CPU 处理时间取决于图像和机器。公共部署需要 HTTPS 和专用管理端点。
