Kerfloom

将照片变成金属艺术品，然后进行连接和切割检查以帮助其粘合在一起。

打开Kerfloom 在 GitHub 上查看

从一次性邀请或来自授权工作区设备的链接开始。缓存的项目可以离线编辑；摄影处理和仅服务器项目需要连接。

关于项目

切割后依然连成一体的艺术。

Kerfloom 将照片和准备好的艺术品转化为 CNC 等离子切割的连接设计。它将图像处理、面板布局、支撑、手动编辑、切口模拟、加密的项目工作区和矢量导出到一个可安装的 Web 应用程序中。

深色区域代表要保留的金属；浅色区域代表要去除的材料。图稿、框架、支撑、笔刷编辑和制造维修保持独立，因此您可以重新做出决定，而无需重新开始。

漂亮的预览只是一个开始。 Kerfloom 根据所选切割轮廓检查几何形状，同时操作员确认实际材料和机器的设置。在记录验证证据之前，配置文件将保持临时标记。

Kerfloom 中提供的视觉处理示例。每个项目在导出之前仍然需要自己的面板、支撑和切割轮廓检查。

应用程序工作流程库

从照片到切割文件

  1. 准备： 导入图像，比较原始图像、色调和图稿，然后选择剪切样式。音调控件保持可用，与风格无关。可选的起始尺寸考虑了面板尺寸和切割轮廓限制。快速预览与处理的几何图形分开标记；制造验证也不是。
  2. 控制板： 设置库存尺寸和方向，然后定位、旋转和缩放图稿。配置框架和锚边并选择用于生成、验证和导出的切割轮廓。艺术品按比例贴合，无需拉伸，未使用的区域保留为金属。
  3. 支持： 找到断开的区域并在接受建议的桥梁之前对其进行审查。绘制支撑自己，使用点击开始/点击结束，或以数字方式调整它们的位置、角度和大小。
  4. 验证： 选择 Run all checks 来比较模拟割缝前后的几何形状。检查个别问题并预览可逆修复。在修复选定的问题时，使用“重新检查选定的问题”来刷新其审查，而不会放弃已接受的修复；退出会清除选择。
  5. 出口： 验证当前切削几何形状后，下载 SVG 或 DXF。一旦几何体存在，PNG 就可用，当验证丢失、过时或阻塞时，会显示可见的草稿水印。可编辑的项目下载仍然可用。文件名标识项目、面板尺寸、样式、框架选择、用途和时间戳。

具有实验空间的模式

这 14 种风格涵盖线条艺术、海报模板、图标模板、图形肖像、剪影、负空间线条、图标/木刻、流雕刻、轮廓带、板条、阴影线、径向切割、可变点和装饰对称。视觉样本和简短描述可帮助您选择起点。

  • 流雕： 长而平行的切割丝带围绕宽广的色调弯曲。节距、宽度、方向、特征跟随、平滑和暗区截止塑造结果，同时尊重选定的开口和成品腹板限制。
  • 径向切割和可变点： 使用向边缘分裂的光线控制实心中心枢纽，或从在 SVG 和 DXF 导出中圆形几何形状保持圆形的点构建色调图案。
  • 可审查的智能支持： 过滤器感知桥可以支持深色面部特征或将稀疏的板条稳定器放置在远离面部的位置。在您接受之前，建议仍然是虚线建议。
  • 您可以重新访问的编辑： 添加、删除和恢复是物理面板单元中的有序操作。选择单个笔画或区域来移动、调整大小、隐藏、更改或删除它，而无需撤消后续工作。绘画会立即更新并标记先前的验证已过时，因此下一个手势不会等待全面板扫描。

随项目保存的验证结果

版本化的切割轮廓记录了工艺、库存、机器或消耗品、几何限制、支持假设和验证证据。项目和保留的导出保留自己的快照，因此结果背后的设置仍然可识别。

切口模拟和修复预览测试配置的几何限制。修复报告解释了发生的变化、剩余的不确定性、尝试停止的原因以及下一步要尝试的内容。验证、修复和智能支持规划会显示进度，并且可以在最后接受的几何图形仍然可用时取消。

在手动材料和支持更正期间，已接受的维修仍然有效。绘制的区域仅覆盖该区域中相反生成的编辑。 Run all checks 当您准备好进行下一次完整验证时；更改底层艺术品、面板几何形状或切割限制会使相关修复变得陈旧并需要重新生成。

保留的导出包括防篡改发布清单，其中包含几何和输出哈希、单位、配置文件设置、补偿合同和验证证据。仅当拓扑和制造检查通过时才接受可选的矢量简化；否则，导出将返回到精确的栅格轮廓。

准备好进行 CAM 审查意味着当前几何体通过了 Kerfloom 的配置检查。操作员仍然验证材料、机器、消耗品、补偿、导入、切割顺序、夹具、热行为和最终使用。新项目导出预期的成品边界，并在 CAM 中仅应用一次内/外切口补偿。

一般等离子轮廓从 2 毫米最小开口和保守的 3 毫米成品间隙/腹板开始。下限需要确认所选库存和机器。在记录验证证据之前，配置文件保持临时状态。

跨设备继续工作

  • 从本地草稿开始： New project 在您的设备上创建一份可恢复草稿。导入并实验，然后选择 Save to Projects 将其添加到加密工作区。在替换未保存的草稿之前启动另一个项目会发出警告。
  • 自动保存和恢复： 工作区项目编辑首先保存在本地并排队等待同步。该应用程序仅在确认后报告服务器保存。源图片和导出一次上传；普通编辑发送较小的状态更新。多达十个恢复点、可恢复垃圾箱和冲突副本有助于保护正在进行的工作。
  • 从缓存中打开的库： 浏览和搜索项目，无需下载整个工作区。选择 Save offline 在设备上保留完整的项目及其源和导出。
  • 链接您的设备： 一次性二维码或专用链接可将另一台设备连接到同一实时工作空间。可以查看和撤销链接的设备。
  • 分享一个独立的副本： 受邀 Kerfloom 设备上的一位收件人可以声明加密快照。链接将在 7、30 或 90 天后过期，并且可以撤销。共享并不能让接收者访问您的实时工作空间；撤销无法删除已导入的副本。
  • 便携式项目： 可编辑 .stencil.json 下载省略了原始照片。加密的工作区和共享包可以在可用时包含它，以及编辑、支持、修复、恢复点和保留的导出。

安装它并使项目离线

在 Windows 上，使用 Edge 或 Chrome 中的安装图标或应用程序/安装菜单。在 Android 上，选择“安装应用程序”或在 Chrome 中选择“添加到主屏幕”。在 iPhone 或 iPad 上，在 Safari 中打开应用程序并选择“共享”，然后选择“添加到主屏幕”。

在线时在授权设备上加载应用程序，并打开仅服务器项目或在断开连接之前选择 Save offline。缓存的项目保持可编辑状态并更改队列，直到同步成功；照相处理仍然需要连接。应用程序更新后，在线打开已安装的副本，以便刷新。

在桌子上或切割台旁边

在移动设备上，画布保持在视图中，而舞台控件在紧凑的底部表格中打开。持久的工具栏可让项目、同步状态、Undo/Redo 和编辑工具保持可访问性。标尺在缩放时会保留物理单位，并在金属和开口上有可见的红色刻度指示器。支持键盘、列表、数字和基于点击的替代方案，平移模式将导航与编辑分开。

该界面包括可见焦点、工作流程选项卡的键盘导航和屏幕阅读器通知。物理设备和辅助技术验收检查仍在进行中。

选择 Help 在应用程序中查找可搜索的手册，或在相关章节中打开阶段的问号按钮。您还可以 阅读 GitHub 上的用户指南.

幕后工具

浏览器处理艺术线条转换、确定性几何、编辑和离线缓存。 Node/Express 服务管理基于邀请的设备访问和加密工作空间；私人 Python/FastAPI 服务使用 OpenCV 和 MediaPipe 进行摄影分析和风格渲染。该应用程序已获得 GPL-3.0-or-later 许可。

有关当前功能列表和技术文档，请参阅 Kerfloom 自述文件.
