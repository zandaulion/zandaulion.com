Casierul clasei

管好班级的钱：谁交了钱、还欠多少、每一列伊都花到了哪里。

打开网页应用 在 GitHub 上查看

已上线的应用仅限受邀使用，界面为罗马尼亚语。

关于该应用程序

Casierul clasei（意为“班级出纳”）面向负责管理班级经费的家长。它把每个孩子的缴费、班级开支和每一笔付款集中记录在一处，让出纳随时知道余额以及谁还没交。一次安装即可管理多个班级和学校，每个班级都有独立的账本。

应用为罗马尼亚语，金额以列伊计。访问需要邀请，每次针对一个班级和一个角色。出纳可以查看和修改所有内容；家长可以看到班级汇总和自己孩子的账户；审核人员可以查看完整账本和报表，但不能做任何修改。只读访问可以在指定日期到期。

它是如何运作的

  1. 设置班级。 添加学校、班级和学年，然后逐个添加孩子，或直接粘贴名单。
  2. 创建开支。 选择参与的孩子以及费用分摊方式：每人固定金额、总额平分，或每人数量乘以单价。
  3. 收款。 点按一个孩子，选择其全部欠款或某一项开支。大按钮会把金额向上取整到下一个 10、50 或 100 列伊，差额可以找零，也可以记为预付款。
  4. 付款并记账。 记录付出的款项，包括去向以及可选的对应开支，并在账本中查看班级余额。

功能

  • 每个孩子的账户： 每个孩子的缴费、欠款、预付款和完整历史。
  • 算得清的预付款： 预付款之后可以抵扣其他缴费，也可以退还；使用预付款绝不会被算作新的收入。
  • 更正不删除： 已确认的操作通过一条单独的更正记录并注明原因来撤销，因此历史始终完整。
  • 精确到最后一个巴尼： 金额以整数巴尼（罗马尼亚的分）存储，分摊总额时会把每一个巴尼都精确分配。
  • 网络不稳也安全： 保存需要联网，但如果响应丢失，重试会确认同一请求，不会重复记账。在其他设备上做出的更改需要先核对再保存。
  • 垫付给班费的钱： 有人自掏腰包为班级付款时，应用会记录这笔钱，必要时关联到某项开支，并显示班级还欠对方多少，直到部分或全部归还。
  • 凭证文件： 为开支和付款附上 PDF 或照片，例如收据。每个文件都有数字指纹，由出纳决定只给出纳和审核人员查看，还是也向班级家长公开。
  • PDF 报表： 在应用内直接预览、分享或下载报表，并用颜色区分：绿色表示已付清，黄色表示部分付款，红色表示逾期，蓝色表示余额和已付出的款项。每份 PDF 都保留签发时学校和班级的徽标与配色。
  • 开支覆盖率： 班级概况、每项开支的报表和缴费明细表都会为每项开支显示一个进度条和百分比：所需金额中已经向孩子们收齐了多少。
  • 多个班级，彼此隔离： 每个班级都有独立的数据库、孩子、开支、报表、徽标和权限。页眉中的选择器可以切换班级，同一台设备在不同班级中可以拥有不同角色。
  • 家长只能看到自己的孩子： 家长的设备只会收到班级汇总和自己孩子的信息，绝不会收到其他孩子的姓名或付款记录。
  • 适配各种屏幕： 在手机上，收款操作随手可及。在平板上，列表会分栏排列；在笔记本电脑上，导航移到侧边，账本会把余额和历史并排显示。旋转屏幕或调整窗口大小时，正在输入的内容会保留。
  • 亲切的外观： 温暖的配色、低调的插图，以及通俗易懂的欠款说明。报表带有笔记本、纸飞机等小小的文具元素，同时金额和表格依然清晰。
  • JSON 导出： 数据及其历史的可读副本，不含任何凭据。

在引擎盖下

Casierul clasei 运行在 Node.js 24 上，使用内置的 SQLite。报表由 PDFKit 生成，并用本地的 PDF.js 副本预览，应用不会从外部服务器加载任何库或字体。它通过 pwa-kit 自动更新，邀请和设备则在 PWA Invite Console 中管理。每日备份在保存前都会检查完整性。该项目以 GPL-3.0 许可证开源。
