Sobre o projeto

Uma metodologia completa, dados históricos, scripts de análise e solicitações de IA para admissão no ensino médio e exame de avaliação nacional em Bucareste.

Este pacote contém um método completo para organizar as opções de admissão no ensino médio, estruturado para que qualquer família possa utilizá-lo com um assistente de IA (ChatGPT, Claude, Gemini).

Galeria

Recursos

  • 📊 Três anos de dados históricos: Mais de 400 cursos de estudo com médias de admissão (2024–2026), vagas especiais para alunos com necessidades educacionais especiais (CES) e taxas de aprovação no bacharelado (2018–2026).
  • 📈 Curvas de classificação e calibração: Algoritmos de interpolação de nota para classificação ajudam a contabilizar as mudanças anuais na dificuldade do exame.
  • 🎲 Simulador de colocação computadorizado: Um script Python simula o algoritmo oficial de posicionamento do ISMB usando a lista ordenada de opções do aluno.
  • 🤖 Manual detalhado do assistente de IA: Os prompts estruturados ajudam um modelo de linguagem a atuar como um assistente de admissão dedicado.
  • 🏫 Preparação para a Reforma de 2027: Um guia para os novos exames de admissão organizados diretamente pelas escolas de ensino médio para até 50% de suas vagas.
  • 🔓 Código aberto e licença gratuita: Gratuito e de código aberto sob a licença MIT, disponível para todos os pais e professores.
