Spendosaurus

Planeje as grandes despesas da família, da primeira estimativa à última parcela.

Abrir o aplicativo web Ver no GitHub

Sobre o projeto

Um Progressive Web App leve e voltado para dispositivos móveis (PWA) projetado para que as famílias monitorem despesas caras, planejem estimativas e controlem pagamentos de forma incremental com atrito zero e gestos de toque intuitivos.

Seja reformando uma casa, planejando um casamento ou gerenciando uma grande compra familiar, o Spendosaurus facilita o rastreamento de variações por meio de dicas visuais instantâneas e ergonomia fluida e móvel.

Galeria

Recursos

  • 🪙 Adição de custos incrementais: Defina um orçamento inicial estimado para uma despesa importante e, em seguida, registre rapidamente cada parcela ou fatura parcial à medida que for paga para monitorar as variações em tempo real.
  • 🟢 10% de tolerância orçamentária: As despesas dentro de 10% do orçamento estimado são consideradas dentro do orçamento com feedback verde limpo antes que os alertas de aviso sejam acionados.
  • 👆 Gestos de deslizar e tocar: Deslize o cartão para a direita para avançar o status do ciclo de vida (Planejado → Em andamento → Concluído), deslize para a esquerda para abrir o detalhamento completo e o histórico de auditoria ou arraste para baixo as planilhas modais.
  • 🔙 Navegação traseira com borda contínua: Integrado diretamente com o histórico do navegador API para que os gestos de retrocesso do Android e iOS desenrolem as telas modais perfeitamente.
  • 💱 Suporte para moeda dupla: Alterne facilmente entre RON e EUR com limites personalizáveis de valor elevado.
  • 🛡️ Emparelhamento baseado em convite: Autenticação perfeita de dispositivos alimentada pelo sistema de convite unificado PWA sem necessidade de senhas ou credenciais.
