# Contributing

Start with the [README](README.md): it identifies source catalogs, generated pages,
preview commands and publication checks. Edit source templates/catalogs, regenerate
the site and include the generated output. Do not hand-edit translated pages.

Use Issues for reproducible bugs or focused project-page corrections. Include the
page path, language and expected text/behavior. Use synthetic screenshots and
examples; never submit private app data, identifiers, credentials or infrastructure
details. Keep existing project and privacy-policy URLs stable.

Run the generation, language and site checks listed under **Checks before publishing**
in the README. Review changed pages in a browser, including mobile and RTL layouts.
Brand assets retain the separate terms described in the README.
