Mișcare

手持ちの道具で、今日の暮らしに少し運動を。

ウェブアプリを開く GitHubで見る

プロジェクトについて

ゼロから始めましょう。自分のペースで動きましょう。罪悪感はありません、調整するだけです。

Mișcare は、日々のフィットネスに伴う心理的および物理的な摩擦をあらゆる層から取り除くように設計されたアダプティブ プログレッシブ Web アプリ (PWA) です。 Mișcare は、まったくの初心者や長い休止から復帰した人向けに特別に設計されており、複雑なセット/レップ スプレッドシート、懲罰的なストリーク カウンター、威圧的なジムの専門用語を排除しています。

アプリを開くと、ユーザーには「今日のセッション」が直接表示され、ワンタップで起動できるようになります。忙しい場合は、ワンクリックの「5 分にする」オプションを使用してワークアウトを短縮します。たとえ何日も生活に支障をきたしても、途切れたり罪悪感を感じたりすることはありません。アプリは、穏やかな再入場ルーチンであなたを歓迎するだけです。

Vanilla JavaScript (ES モジュール) とネイティブ SQLite を備えた Node.js で構築された Mișcare は、Gemini Vision と統合して写真から利用可能な家庭用機器を認識し、pwa-kit はダウンタイムなしのオフライン キャッシュとシームレスなアップデートを実現し、pwa-invite-console はパスワードなしのデバイス オンボーディングを実現します。

ギャラリー

機能

  • 🌱 ゼロから始める: 安全で基本的な自重運動 (壁腕立て伏せ、椅子に座って立つ動作、緩やかな臀筋ブリッジ、肩の可動性ストレッチ) と、温かみのあるイラスト入りのビジュアルガイドおよび膝、腰、手首の保護フィルターが組み合わされています。
  • ⚡ ゼロフリクションの毎日のセッション: ホーム画面では、今日のルーチンがすぐに実行されます。などのワンタップのバリエーションが含まれています 「5分くらいにしてください」 そして 「スワップ練習」、静かなタイマーと Web オーディオ API チャイムが伴います。
  • 📸 Gemini ビジョン機器の認識: 家庭用品や運動器具（ダンベル、レジスタンスバンド、ヨガマット、頑丈な椅子）の写真を撮ります。 Google Gemini Vision はアイテムを自動的に検出し、一致するエクササイズのバリエーションのロックを解除します。
  • 🌿「恥をかかない」適応ロジック: アクティブな日数は、壊れやすい連続記録ではなく、永続的なマイルストーンとして蓄積されます。セッションが「少し厳しい」と評価された場合、次のルーチンは自動的に強度を下げます。休憩後に戻った場合は、自動的に穏やかな再適応セッションがスケジュールされます。
  • 🔄 PWA Kit 経由の即時アップデート: と統合 pwa-kit コンテンツ ハッシュ バージョン スタンピングと無停止更新プロンプトを備えたネットワーク ファーストの Service Worker キャッシュ用。
  • 🔐 パスワードレスのデバイスペアリング: シームレスなオンボーディング pwa-invite-console ペアリングコード (XXXX-YYYY-ZZZZ) 安全で有効期間の長いデバイス セッション トークンを発行します。
  • 🎨 デュアルテーマとオフライン復元力: 森のエメラルドのアクセントを備えた自動明暗パレット。IndexedDB と LocalStorage によってオフラインで完全に機能します。

アーキテクチャと技術スタック

フロントエンドのアーキテクチャ

ビルドステップのオーバーヘッドのないバニラ JavaScript (ES モジュール)、応答性の高い CSS カスタム プロパティ、カスタム Web オーディオ合成、および Service Worker オフライン キャッシュ。

バックエンドエンジン

ネイティブを活用した Node.js v24 DatabaseSync から node:sqlite、Express REST エンドポイント、および Google Gemini Multimodal Vision API 統合。

統合

バージョン ライフサイクル管理用の pwa-kit と、招待トークン引き換えとデバイス管理用の pwa-invite-console とのネイティブ コントラクト互換性。
