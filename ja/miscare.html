Mișcare

手持ちの道具で、今日の暮らしに少し運動を。

Google Playでダウンロード ウェブアプリを開く GitHubで見る APKをダウンロード

Android アプリ

Mișcare は Android 7.0 以降向けに Google Play で公開されており、バージョン 0.1.1（2026年11月3日）から本番提供中です。ガイド付きルーティン、イラスト付きの45種目、12の表示言語、ライト／ダークテーマ、JSON バックアップ付きのローカルな運動記録を備えています。アカウント、サーバー、インターネット権限は不要です。

バージョン 0.1.1 では、すべての画面が選んだ言語で表示され、キープする運動は回数ではなく秒数で数え、自重だけでも「ゼロから」があなたのレベルのまま保たれます。ダークテーマも追加され、目安の時間は選んだセット数に合わせて変わるようになりました。

手動でインストールする場合は、署名済み APK を GitHub Releasesからダウンロードしてください。Play 版とは署名が異なるため、互いに更新することはできません。切り替える前にデータを書き出してください。Android アプリは PWA の履歴を取り込まず、JSON の読み込みは現在のプロフィールと記録を置き換えます。チェックサム、署名、残りの確認事項については インストールとバックアップのガイド をご覧ください。リマインダーは実装されていません。

プロジェクトについて

ゼロから始めましょう。自分のペースで動きましょう。罪悪感はありません、調整するだけです。

Mișcare は、Google Play の Android アプリと自分でホストする Web 版を持つ、適応型の運動アプリです。初心者や、しばらく休んでから再開する人のために作られており、短いルーティン、器具の選択、記録を備えています。レベルを上げるかは自分で選べ、休んだ日に連続記録が途切れるペナルティはありません。

アプリを開くと、ユーザーには「今日のセッション」が直接表示され、ワンタップで起動できるようになります。忙しい場合は、ワンクリックの「5 分にする」オプションを使用してワークアウトを短縮します。たとえ何日も生活に支障をきたしても、途切れたり罪悪感を感じたりすることはありません。アプリは、穏やかな再入場ルーチンであなたを歓迎するだけです。

自分でホストする PWA は Vanilla JavaScript、Node.js、SQLite を使い、pwa-kit による更新と pwa-invite-console による端末招待に対応しています。Android アプリはインターフェースと適応エンジンを Capacitor に組み込み、プロフィールと記録を IndexedDB に端末内で保存し、Google Play または新しい署名済み APK のインストールで更新されます。

ギャラリー

機能

  • 🌱 ゼロから始める: 自重による基本の動き（壁腕立て伏せ、椅子からの立ち上がり、やさしいヒップリフト、肩の可動域ストレッチ）を、12言語のイラスト付きガイドと、ひざ・腰・手首を守るフィルターと組み合わせています。
  • ⚡ ゼロフリクションの毎日のセッション: ホーム画面では、今日のルーチンがすぐに実行されます。などのワンタップのバリエーションが含まれています 「5分にする」 そして 「別の種目に替える」。控えめなタイマーと Web Audio API によるやさしい音が付きます。セット数は1・2・3から選べ、目安の時間もそれに合わせて変わります。
  • 🔁 入れ替わるセッション： セッションを完了するたびにローテーションが進むので、自分に合うすべての種目を順に行えます。休んだ日があっても、やり損ねたセッションがそのまま戻ってきます。動きのパターン（押す、引く、スクワット、股関節、体幹、ふくらはぎ、運ぶ）も交互になるため、毎回同じグループが入ることはありません。キープする運動は秒数で数えます。
  • 機器フィルター: 所有している機器と保護したい領域を選択してください。ルーチンはそれらの選択に適応します。
  • 🌿「恥をかかない」適応ロジック: アクティブな日は、途切れやすい連続記録ではなく、消えない達成として積み重なります。セッションを「少しきつい」と評価すると次のルーティンの強度が自動で下がり、4日以上空けて戻ると、やさしい再開用のセッションが自動で組まれます。
  • 🔄 PWA アップデート: と統合 pwa-kit コンテンツ ハッシュ バージョン スタンピングと無停止更新プロンプトを備えたネットワーク ファーストの Service Worker キャッシュ用。
  • 🔐 PWA デバイスのペアリング: シームレスなオンボーディング pwa-invite-console ペアリングコード (XXXX-YYYY-ZZZZ) 安全で有効期間の長いデバイス セッション トークンを発行します。
  • 🎨 ライト／ダークテーマとオフライン対応： スマートフォンのテーマに合わせるか、設定で選べます。エメラルドグリーンのアクセントで、IndexedDB と LocalStorage により完全にオフラインで動作します。

アーキテクチャと技術スタック

フロントエンドのアーキテクチャ

ビルドステップのオーバーヘッドのないバニラ JavaScript (ES モジュール)、応答性の高い CSS カスタム プロパティ、カスタム Web オーディオ合成、および Service Worker オフライン キャッシュ。

バックエンドエンジン

PWA の構成要素は Node.js 24、組み込みの node:sqlite、Express REST API です。Android 版は共通の運動メニューエンジンをローカル実行するため、バックエンドは不要です。

統合

バージョン ライフサイクル管理用の pwa-kit と、招待トークン引き換えとデバイス管理用の pwa-invite-console とのネイティブ コントラクト互換性。
