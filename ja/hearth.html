Hearth OCR

血圧計の写真をブラウザー内で読み取る実験的なツールです。すべての数値をご自身で確認してください。

実験的プレビューをダウンロード · 0.1.0 リリースノートとSHA-256 GitHubで見る

ブラウザー用の実験的なプレビュー

Hearth は、一般的な縦型・3行表示の血圧計の写真から最高血圧（SYS）、最低血圧（DIA）、脈拍を読み取ります。写真を選択するかカメラを使い、画面部分を切り抜いて、コピー前に結果を修正してください。

結果を使用またはコピーする前に、すべての数値を血圧計の表示と照合してください。 これは実験的な OCR であり、検証された医療リーダーではありません。新しい現実世界の写真の認識精度はまだ証明されていません。

プレビューを試してみる

添付のリリース ZIP をダウンロードして解凍します。これには、ソース、2 つの ONNX モデル、およびブラウザー ランタイムが含まれています。アカウント、npm インストール、モデルのトレーニングは必要ありません。 Python 3.12 以降を推奨します。

抽出したフォルダーから次を実行します。

python3 prototype/serve.py

同じコンピュータ上の現在のブラウザを使用して、ローカル プレビューを開きます。

http://127.0.0.1:8765/

サーバーはあなたのコンピュータ上でのみリッスンします。別のデバイスからのカメラ アクセスには、HTTPS などの安全なブラウザ コンテキストが必要です。

仕組み

検出器がディスプレイを検出し、数字認識器がその行を読み取ります。 ONNX 推論はブラウザー ワーカーで実行されます。整合性チェックとクロップの再試行では、不確実な結果が拒否または再試行される可能性があります。正しい読み取りを保証するものではありません。

プライバシーとオフラインでの使用

通常の写真処理はブラウザのメモリに残ります。アプリは写真をアップロードしたり保存したりしません。最初の読み込みが完了すると、Service Worker はオフラインで使用できるようにアプリとモデルをキャッシュします。ローカル開発評価ツールは別のワークフローです。

再利用と統合

オリジナルコードと同梱モデルは AGPL-3.0-only です。ONNX Runtime Web は MIT ライセンスを維持します。モデルカードには来歴、チェックサム、制約を、統合ガイドには別のアプリで再利用する方法を記載しています。
