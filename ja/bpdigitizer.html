Android および Web 形式の 1 つの血圧ログ。測定値を記録し、傾向を調査し、履歴をエクスポートします。

BP Digitizer は、血圧の測定値を記録し、その履歴を見て、自分の記録を残すためのアプリです。Android のネイティブアプリを使うか、ブラウザーで PWA を開いてください。どちらも自分の端末上でカメラを使って血圧計を読み取れ、アカウントは必要ありません。以前ここで wBP Digitizer として紹介していたウェブ版も、同じプロジェクトの一部です。

ウェブ用 BP Digitizer

PWA は同じプロジェクトをブラウザーで使えるようにしたもので、カメラ読み取り、手入力、グラフ、書き出しに対応しています。測定値はブラウザーの IndexedDB にローカル保存され、アプリは GitHub Pages から配信されます。背後にサーバー、アカウント、招待はありません。ホーム画面にインストールしておくと便利です。

ウェブアプリの内部

これらのスクリーンショットの測定値とプロフィール情報はすべて架空のものです。

ウェブ機能

  • 📱 ローカルファースト & PWA: ホーム画面にインストールされ、オフラインでも動作します。測定値はブラウザの IndexedDB 内に存在し、どこにも送信されることはありません。
  • 📷 端末上でのカメラ読み取り: 3 行表示の血圧計にカメラを向けると、ブラウザーで動くモデルが SYS、DIA、脈拍を読み取ります。保存前に 3 つの値をすべて確認し、確実に読めない写真は推測せずに読み取りを断ります。
  • ✏️ 素早い入力: 前回の測定値から始まるスライダー、数値欄、長押しでの増減。
  • 📈 総合的なチャート: 傾向グラフ (収縮期 + 拡張期、120/80 基準線) および収縮期対拡張期の散布図。 7 / 30 / 90 日および全時間範囲。
  • 🧠 スマート分析: バースト平均化では、連続して取得された測定値が 1 つの点にまとめられます。デバイス上で計算された分析情報 (朝と夕方、範囲内の時間、健全な連続記録、コンテキスト タグ)。
  • 🩺 臨床ロジック: AHA 区分(正常 / 高め / ステージ 1 / ステージ 2 / 危険域)、平均動脈圧と脈圧、BMI、健康プロフィールからのリスク評価。
  • 📄 エクスポートとレポート: CSV と JSON の読み込みと書き出し、印刷やダウンロードができる PDF レポート。
  • 🔐 暗号化バックアップ: 測定値とプロフィールを、パスフレーズで暗号化したファイルにバックアップし、別の端末で復元できます。失ったパスフレーズは誰にも復元できません。
  • 🌐 グローバル: Android アプリから引き継いだ 12 言語に対応し、翻訳し直してはいません。アラビア語の右から左への表示にも対応しています。

Android用BP Digitizer

Android のネイティブアプリは、カメラでの血圧計の読み取りをすべてスマートフォン上で行い、すばやい手入力、推移の表示、Health Connect、PDF の書き出し、リマインダーも備えています。インターネットの権限はなく、Android のクラウドバックアップと端末間の移行もこのアプリでは無効なので、書き出さない限り測定値はスマートフォンの中に残ります。Android 8.0 以降の ARM64 スマートフォンで動作します。

アプリは F-Droid に提出済みで、まだダウンロードできません。 代わりに Web バージョンを開いてください ↗

Android アプリ内

バージョン 1.6.2 で撮影。測定値とプロフィールの値はすべて架空のものです。

Androidの機能

  • 🏃 アクティブなライフスタイル向けに設計: 血圧は、歩数、トレーニング、睡眠と並ぶ健康指標の中心です。数秒で記録し、動き続けるためのルーチンの一部として保存します。
  • ✏️ 測定値を数秒で無料で記録します: 高速でタップしやすいスライダーを使用して、収縮期、拡張期、脈拍を瞬時に設定できます。完全に無料で、オフラインで動作し、アカウントは必要ありません。初めてアプリを開いたときに追跡を開始します。
  • 📷 またはカメラでオフライン読み取り: 入力したくないときは、血圧計の表示を撮影するだけで、アプリに組み込まれたモデルがインターネットに接続せずにスマートフォン上で値を読み取ります。無料で、保存前には必ず値を確認します。
  • 📈 自分の傾向に注目してください: 数日、数週間、数か月にわたって数値がどのように推移するかを確認します。傾向線と 3D 散布図を切り替えて、指で回転させて、収縮期、拡張期、脈拍を一緒に調査できます。スマートな「平均」平滑化により、連続した測定値が 1 つの正直なデータ ポイントにマージされるため、傾向が現実を反映します。スマートフォンを横にすると、両方のグラフを並べて見られます。
  • 🏷️ 何が数字を動かすのかを確認してください: 運動、カフェイン、塩辛い食事、睡眠不足、ストレスなど、読んだ内容にコンテキストをタグ付けして、自分の活動やライフスタイルが時間の経過とともにどのように数値に影響を与えるかを確認します。
  • ❤️ ヘルスコネクトと接続: ダッシュボードから測定値を Android Health Connect にコピーすれば、血圧を活動量、ワークアウト、その他のフィットネスデータと並べて管理できます。任意の機能で、自分で選んだときだけ行われます。
  • 📄 自分自身の記録を保管してください: JSON バックアップ、CSV ファイル、グラフと測定値を含む複数ページの PDF レポートを書き出せます。このアプリやウェブ版のバックアップも読み込めます。
  • ⏰ 一貫した習慣を築く: オプションの穏やかなリマインダーを使用すると、毎朝と夕方に同時に記録できるため、傾向を完全に保つことができます。
  • 🔒 設計によるプライベート: アプリにはインターネットの権限が一切ありません。作成するアカウントも、クラウドへの登録もなく、販売や共有もされません。コピーを残したり新しいスマートフォンへ移ったりするには、JSON バックアップを書き出してください。あなたの数値はあなただけのものです。
  • 🌐 12 言語: 英語、アラビア語、中国語、フランス語、ドイツ語、ヒンディー語、日本語、韓国語、ポルトガル語、ルーマニア語、スペイン語、ウクライナ語。
