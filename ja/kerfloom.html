Kerfloom

写真を金属アートに変換し、それを結合するのに役立つ接続と切断チェックを実行します。

Kerfloomを開く GitHubで見る

1 回限りの招待または承認されたワークスペース デバイスからのリンクから始めます。キャッシュされたプロジェクトはオフラインで編集できます。写真処理やサーバーのみのプロジェクトには接続が必要です。

プロジェクトについて

切り抜いても、ひとつにつながるアート。

Kerfloom は、写真と準備されたアートワークを、CNC プラズマ切断用の接続されたデザインに変換します。画像処理、パネル レイアウト、サポート、手動編集、カーフ シミュレーション、暗号化されたプロジェクト ワークスペース、ベクター エクスポートを 1 つのインストール可能な Web アプリにもたらします。

暗い部分は保持すべき金属を表します。明るい領域は、除去するマテリアルを表します。アートワーク、フレーム、サポート、ブラシ編集、製造上の修復は別々に行われるため、最初からやり直すことなく決定を再検討できます。

見栄えの良いプレビューは始まりにすぎません。 Kerfloom は、選択した切断プロファイルに対して形状をチェックし、オペレーターは実際の材料と機械の設定を確認します。検証証拠が記録されるまで、プロファイルは「暫定」としてマークされたままになります。

パラメトリック カット スタイル ギャラリー

Kerfloom で利用できる視覚処理の例。各プロジェクトには、エクスポート前に独自のパネル、サポート、切断プロファイルのチェックが必要です。

アプリケーションワークフローギャラリー

写真からカッティングファイルまで

  1. 準備するもの: 画像をインポートし、オリジナル、トーン、アートワークを比較して、カット スタイルを選択します。トーン コントロールはスタイルに関係なく使用できます。オプションの開始寸法は、パネル サイズと切断プロファイルの制限を考慮したものです。クイック プレビューには、処理されたジオメトリとは別にラベルが付けられます。製造検証でもありません。
  2. パネル： ストックの寸法と向きを設定し、アートワークの位置、回転、拡大縮小を行います。フレームとアンカーエッジを設定し、生成、検証、エクスポートに使用する切断プロファイルを選択します。アートワークは伸びることなく比例してフィットし、未使用の領域は金属として保持されます。
  3. サポート: 切断されたエリアを見つけて、提案されたブリッジを受け入れる前に確認してください。 Draw は自分自身をサポートし、タップ スタート/タップ エンドを使用するか、位置、角度、サイズを数値で調整します。
  4. 検証: Run all checks を選択して、シミュレートされたカーフの前後のジオメトリを比較します。個々の問題を検査し、元に戻せる修復をプレビューします。選択した問題を修正するときに、受け入れられた修理を破棄せずに、選択した問題の再確認を使用してレビューを更新します。エスケープすると選択がクリアされます。
  5. エクスポート: 現在の切削形状が検証されたら、SVG または DXF をダウンロードします。 PNG は、ジオメトリが存在するとすぐに使用可能になり、検証が欠落している、古い、またはブロックされている場合にはドラフト透かしが表示されます。編集可能なプロジェクトのダウンロードも引き続き利用できます。ファイル名は、プロジェクト、パネル サイズ、スタイル、フレームの選択、目的、およびタイムスタンプを識別します。

実験の余地のあるパターン

14 のスタイルには、線画、ポスター ステンシル、アイコン ステンシル、グラフィック ポートレート、シルエット、ネガティブスペース線画、アイコン / 木版画、フロー彫刻、輪郭バンド、スラット、ハッチ、放射状カット、可変ドット、装飾対称が含まれます。視覚的な見本と短い説明は、開始点を選択するのに役立ちます。

  • フロー彫刻： 平行にカットされた長いリボンが、幅広い色調のフォルムに沿って曲がります。ピッチ、幅、方向、フィーチャ追従、スムージング、および暗部カットオフにより、選択した開口部と完成したウェブの制限を尊重しながら結果が形成されます。
  • 放射状カットと可変ドット: エッジに向かって分割する光線で固体の中央ハブを制御したり、SVG および DXF エクスポートで円のジオメトリが丸いままであるドットから色調パターンを構築したりできます。
  • レビュー可能なスマート サポート: フィルター対応ブリッジは、暗い顔の特徴を優先したり、まばらなスラット スタビライザーを顔から離して配置したりできます。提案は、承認されるまで破線の提案のままになります。
  • 再訪できる編集: 追加、削除、および復元は、物理パネル単位で順序付けされた操作です。個々のストロークまたは領域を選択すると、後の作業を元に戻さずに、移動、サイズ変更、非表示、変更、または削除できます。ペイントはすぐに更新され、以前の検証が古いものとしてマークされるため、次のジェスチャはパネル全体のスキャンを待ちません。

プロジェクトとともに保存される検証結果

バージョン管理された切断プロファイルには、プロセス、ストック、機械または消耗品、形状制限、サポートの仮定、および検証証拠が記録されます。プロジェクトと保持されたエクスポートは独自のスナップショットを保持するため、結果の背後にある設定は識別可能なままになります。

切り溝シミュレーションと修復プレビューは、設定されたジオメトリ制限をテストします。修復レポートには、何が変更されたのか、残っている不確実性、試行が停止した理由、次に試行すべき内容が説明されます。検証、修復、およびスマート サポートの計画には進行状況が表示され、最後に受け入れられたジオメトリが使用可能なままであればキャンセルできます。

受け入れられた修理は、手動による資料およびサポートの修正中もアクティブなままです。ペイントされた領域は、その領域内で生成された反対側の編集のみをオーバーライドします。 Run all checks 次の完全な検証の準備ができたとき。基礎となるアートワーク、パネルの形状、または切断限界を変更すると、依存する修復が古くなり、再生成が必要になります。

保持されるエクスポートには、ジオメトリと出力ハッシュ、単位、プロファイル設定、補償契約、および検証証拠を含む改ざん明示的なリリース マニフェストが含まれます。オプションのベクトルの単純化は、トポロジーと製造チェックに合格した場合にのみ受け入れられます。それ以外の場合、エクスポートは正確なラスター輪郭に戻ります。

CAM レビューの準備完了とは、現在のジオメトリが Kerfloom の構成されたチェックに合格したことを意味します。オペレーターは引き続き、材料、機械、消耗品、補正、リードイン、カットオーダー、治具、熱挙動、および最終用途を検証します。新しいプロジェクトは、CAM で内側/外側のカーフ補正を 1 回だけ適用して、意図した完成品の境界をエクスポートします。

一般的なプラズマ プロファイルは、2 mm の最小開口部と控えめな 3 mm の仕上げギャップ/ウェブから始まります。下限値は、選択したストックとマシンの確認が必要です。検証証拠が記録されるまで、プロファイルは暫定的なままになります。

複数のデバイスで作業を続ける

  • ローカル ドラフトから始めます。 New project は、デバイス上に回復可能なドラフトを 1 つ作成します。インポートして実験し、Save to Projects を選択して暗号化されたワークスペースに追加します。別のプロジェクトを開始すると、保存されていないドラフトを置き換える前に警告が表示されます。
  • 自動保存と回復: ワークスペース プロジェクトの編集は、まずローカルに保存され、同期のためにキューに入れられます。アプリは、確認後にのみサーバーの保存を報告します。ソース画像とエクスポートは一度アップロードします。通常の編集では、より小さな状態更新が送信されます。最大 10 個の回復ポイント、回復可能なゴミ箱、および競合コピーにより、進行中の作業を保護できます。
  • キャッシュから開くライブラリ: ワークスペース全体をダウンロードしなくても、プロジェクトを参照して検索できます。完全なプロジェクトとそのソース、およびエクスポートをデバイス上に保持するには、Save offline を選択します。
  • デバイスをリンクします: ワンタイム QR コードまたはプライベート リンクは、別のデバイスを同じライブ ワークスペースに接続します。リンクされたデバイスは確認して取り消すことができます。
  • 独立したコピーを共有します。 暗号化されたスナップショットは、招待された Kerfloom デバイス上の 1 人の受信者が要求できます。リンクは 7、30、または 90 日後に期限切れになり、取り消すことができます。共有しても、受信者はライブ ワークスペースにアクセスできません。取り消しによって、すでにインポートされたコピーを消去することはできません。
  • 移植可能なプロジェクト: 編集可能 .stencil.json ダウンロードでは元の写真は省略されます。暗号化されたワークスペースと共有パッケージには、利用可能な場合、編集、サポート、修復、復旧ポイント、および保持されたエクスポートとともに含めることができます。

インストールしてプロジェクトをオフラインにする

Windows では、Edge または Chrome のインストール アイコンまたはアプリ / インストール メニューを使用します。 Android の場合、Chrome で [アプリをインストール] または [ホーム画面に追加] を選択します。 iPhone または iPad では、Safari でアプリを開き、[共有]、[ホーム画面に追加] の順に選択します。

オンライン中に承認されたデバイスにアプリをロードし、切断する前にサーバー専用プロジェクトを開くか、Save offline を選択します。キャッシュされたプロジェクトは編集可能な状態を維持し、同期が成功するまでキューが変更されます。写真処理にはまだ接続が必要です。アプリの更新後、インストールされたコピーをオンラインで開き、更新できるようにします。

机の上、またはカッティングテーブルの横で

モバイルでは、ステージ コントロールがコンパクトなボトム シートで開いている間、キャンバスは表示されたままになります。永続的なツール レールにより、プロジェクト、同期状態、Undo/Redo、編集ツールへのアクセスが維持されます。ルーラーはズームしても物理単位を維持し、金属と開口部の上に赤いスケール インジケーターが表示されます。キーボード、リスト、数値、タップベースの代替手段がサポートされており、パン モードによりナビゲーションが編集から分離されます。

このインターフェイスには、表示されるフォーカス、ワークフロー タブのキーボード ナビゲーション、およびスクリーン リーダーの通知が含まれています。物理デバイスと支援技術の受け入れチェックは引き続き進行中です。

選択 Help アプリ内で検索可能なハンドブックを参照するか、関連する章でステージの疑問符ボタンを開きます。また、 GitHub のユーザーガイドをお読みください.

舞台裏の道具

ブラウザは、線画の変換、決定論的ジオメトリ、編集、およびオフライン キャッシュを処理します。 Node/Express サービスは、招待ベースのデバイス アクセスと暗号化されたワークスペースを管理します。プライベート Python/FastAPI サービスは、写真分析とスタイル レンダリングに OpenCV および MediaPipe を使用します。アプリケーションは GPL-3.0-or-later の下でライセンスされています。
