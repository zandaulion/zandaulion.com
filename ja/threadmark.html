Threadmark

にぎやかな WhatsApp グループと Gmail を、自分に関係のあることだけの短いリストに。支払い、打ち合わせ、締め切りを拾い出します。

GitHubで見る

Threadmark はセルフホスト型です。各自がそれぞれ専用のコピーを動かします。

アプリについて

Threadmark は、あなたが選んだ WhatsApp のグループや相手、Gmail のラベルや送信者のための、プライベートな「要対応」受信箱です。新しいメッセージを届いた順に読み、支払い、打ち合わせ、締め切り、そのほか見張るよう頼んだことを拾い出して、それだけを表示します。それ以外は WhatsApp や Gmail に残ります。

WhatsApp Web と同じくリンク済みデバイスとして接続し、設計上は読むだけです。メッセージを送ることも、チャットを既読にすることも、オンライン表示にすることも、過去の履歴を読むこともありません。この接続は非公式なので、WhatsApp が仕様を変えたり、使っているアカウントを制限したりする可能性があります。

Gmail は Google の読み取り専用アクセスで接続するため、Threadmark はメールの送信、削除、既読化ができません。接続した時点から始まり、古いメールは取り込まず、メール全文を取得するのはオンにしたラベルや送信者からのものだけで、添付ファイルは一切ダウンロードしません。

グループ、相手、Gmail ラベル、送信者はどれも、オンにするまではオフのままです。ほかの経路からのメッセージは確認や保存の前に破棄され、選んだメッセージでも何にも当てはまらなかったものは保存されません。

ギャラリー

これらのスクリーンショットのチャットは架空のものです。

仕組み

  1. 経路をつなぐ。 WhatsApp を QR コードかペアリングコードでデバイスとしてリンクし、必要なら Gmail を読み取り専用アクセスで接続します。
  2. 見張る対象を選ぶ。 見張りたいグループ、相手、Gmail ラベル、送信者だけをオンにします。名前や番号で検索したり、スマートフォンから連絡先を取り込んだりできます。
  3. 仕分けを任せる。 組み込みの検出器と自分のフレーズルールが、新しいメッセージを 1 件ずつサーバー上で確認します。何も当てはまらず Jev がオンなら、AI サービスがもう一度目を通します。
  4. 大事なことに対応する。 項目を完了にする、スヌーズする、カレンダーに追加する、間違えたときに Threadmark に伝える、といった操作ができます。

機能

  • 支払いと打ち合わせをローカルで検出: 内蔵の検出器はルーマニア語と英語のメッセージを読み、金額、通貨、IBAN、日付、時刻、リンクを取り出します。請求書は金額がなくても拾い、サブスクリプションの更新、価格の変更、支払いの失敗も追跡します。領収書や、誰かがすでに済ませた支払いの報告は通知しません。
  • 自分だけのルール: フレーズルールは、指定した語のいずれか、またはすべてに一致し、大文字・小文字やアクセント記号を区別せず、サーバーの外に出ることはありません。ルールごとに対象のチャットを絞り、通知するかどうかを決め、事前にサンプルで試せます。ルールとモニターは個人データを含まない形で書き出せるので、共有やバージョン管理に使えます。
  • ふだんの言葉で書くモニター: 注意が必要な荷物や予約のように、見張りたい内容を一文で書き、Jev がどれだけ確信したらメッセージを知らせるかを決めます。
  • AI はあくまで予備: ローカルで何も当てはまらないときは、TypeSafe AI のオプションサービス Jev が支払い、打ち合わせ、リマインダーを探し、緊急度を判定します。Jev が受け取るのはメッセージ本文だけで、チャット名、送信者、メールアドレス、電話番号、WhatsApp や Gmail の ID は送られません。
  • プロモーションは脇へ: 何も求めてこないニュースレターや一斉配信のオファーは、受信箱ではなく Promotional ビューに静かに移ります。請求書、支払いの依頼、自分で作ったルールに当てはまるものは常に受信箱に残り、振り分けを誤った項目はワンタップで戻せます。
  • Personal と Dev のプロファイル: 仕事用の Gmail アカウントを、専用のフィード、経路、ルール、件数とともに分けておけます。上部の切り替えで、それぞれの要対応件数がわかります。
  • 締め切りと緊急度: 期日はメッセージから読み取られ、項目には期限間近や期限切れのバッジが付き、緊急のものは上に表示されます。
  • 支払いの警告: 変更された口座情報、変わった金額、重複の可能性、パスワードや支払いを求める不自然な依頼には、念のため確認するよう印が付きます。
  • 添付ファイルはローカルで読み取り: 写真、PDF、ボイスメッセージは、文字認識と音声の文字起こしでサーバー上で読み取り、すぐに削除できます。読めなかった手書きのメモは、写真を確認するためのリマインダーになります。
  • 変更と返信: Threadmark は、予定の訂正や取りやめに気づいたり、返信したら返信リマインダーを閉じたりできます。どちらも初期設定ではオフで、直近の本文を最大 48 時間だけ保持します。
  • 通知と毎日のまとめ: 新しい項目のプッシュ通知。対応環境では Done と Actions のボタン付きで、緊急の項目には緊急のタイトルが付き、好きな時刻に届く日次サマリーも選べます。画面に残った通知は積み重ならず、1 つのまとめにまとまります。
  • 保存は短く: 検出した抜粋は、項目が未対応のまま残っていない限り、初期設定では 30 日後に削除されます。

ボンネットの下で

Threadmark は各部分をそれぞれ root 権限なしの Podman コンテナで動かします。ブリッジは Baileys ライブラリで WhatsApp との接続を保ち、Personal 用と Dev 用に分かれた Gmail コネクタはそれぞれ暗号化したログイン情報を持ち、どのコネクタもアプリが受け取るまで各メッセージをキューに残します。アプリは Node.js 24 と内蔵の SQLite で動き、server-sent events と Web Push でブラウザに更新をリアルタイムに送ります。コネクタは外部にポートを開きません。利用は招待制で PWA Invite Console から管理し、アプリは pwa-kit で自動更新されます。メッセージは中立的な形式でアプリに届くため、WhatsApp に Gmail が加わり、今後 Telegram などほかの経路も加えられます。このプロジェクトは GPL-3.0 ライセンスのオープンソースです。
