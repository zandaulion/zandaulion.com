Spendosaurus

最初の見積もりから最後の分割払いまで、家族の大きな出費を計画。

ウェブアプリを開く GitHubで見る

プロジェクトについて

家族向けに設計された軽量のモバイルファースト プログレッシブ Web アプリ (PWA) は、スムーズなタッチ ジェスチャと直感的なタッチ ジェスチャを使用して、高額な出費を追跡し、見積もりを計画し、支払いを段階的に実行できるように設計されています。

家の改築、結婚式の計画、家族の大きな買い物の管理など、Spendosaurus を使用すると、瞬時の視覚的手がかりと流動的なモバイル ファーストの人間工学により、差異の追跡が簡単になります。

ギャラリー

機能

  • 🪙 増分コストの追加: 主要な支出の最初の見積予算を設定し、支払いのたびに各分割払いまたは一部の請求書をすぐに記録して、差異をリアルタイムで監視します。
  • 🟢 10% の予算許容範囲: 推定予算の 10% 以内の支出は予算内とみなされ、警告アラートがトリガーされる前にクリーンな緑色のフィードバックが表示されます。
  • 👆 スワイプとタッチのジェスチャー: カードを右にスワイプしてライフサイクル ステータスを進めます (計画→進行中→完了)。左にスワイプして完全な内訳と監査履歴を開くか、モーダル シートを下にドラッグします。
  • 🔙 シームレスなエッジバックナビゲーション: ブラウザ履歴 API と直接統合されているため、Android および iOS のエッジ バック ジェスチャはモーダル画面をシームレスに巻き戻します。
  • 💱 二重通貨サポート: カスタマイズ可能な高額しきい値を使用して、RON と EUR を簡単に切り替えます。
  • 🛡️ 招待ベースのペアリング: 統一された PWA 招待システムを活用したシームレスなデバイス認証。パスワードや資格情報は不要です。
