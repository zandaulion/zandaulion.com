ゲームについて

OrbitPuzzles は、プレイヤーが惑星、月、小惑星などの天体を戦略的に配置して軌道システムを設計する、挑戦的な物理ベースのパズル ゲームです。目標は、中心星に衝突したり星系から脱出したりすることなく、特定の数の軌道を完了するなど、特定の構成を達成することです。

Kotlin で完全にネイティブに構築された OrbitPuzzles は、Velocity Verlet 統合と Plummer ソフト化を使用した、非常に安定したカスタム $O(N^2)$ N-body シミュレーターを備えています。設計フェーズでは時間が停止するため、慎重に体の位置を決めて速度ベクトルを調整できます。その後、実行フェーズに流れて、軌道力学が持ちこたえるかどうかをテストします。

ビジュアル エクスペリエンスは、Google Filament による 3D レンダリングと 100% Jetpack Compose UI を組み合わせています。各天体はカスタム プロシージャル テクスチャリングを使用してレンダリングされ、大規模なテクスチャ ファイルに依存せずに無限の種類の惑星や恒星を作成し、光る軌跡と UI オーバーレイがリアルタイムのテレメトリとフィードバックを提供します。

ギャラリー

機能

  • カスタム物理エンジン: Velocity Verlet の統合を活用した正確な N 体シミュレーションにより、長期間の軌道安定性を実現し、極度の接近遭遇に適切に対処するための Plummer ソフト化を備えています。
  • 設計と実行のフェーズ: 計画のために時間が停止する戦術的アプローチにより、シミュレーションを開始する前に惑星のセットアップ、力のベクトルを微調整し、軌道パズルを解くことができます。
  • プロシージャル 3D 惑星: 数学的に生成された正距円筒アルベド マップを使用した Google Filament の統合により、アプリのフットプリントを小さく保ちながら、すべての天体が確実にユニークに見えるようになります。
  • ハイブリッド レンダリング: Jetpack Compose Canvas で描画された、美しく階層化されたリアルタイム 2D UI オーバーレイの下でのネイティブ 3D 物理レンダリングの完璧なブレンド。
  • プログレッシブチャレンジ: 明確な予算と目標を持って、幅広いレベルをナビゲートします。内部の「OrbitTracker」システムは、楕円離心率に関係なく回転数を正確に計測します。
