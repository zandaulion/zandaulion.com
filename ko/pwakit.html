pwa-kit

웹 앱이 오프라인에서도 작동하고 최신 상태를 유지하도록 돕는 작은 구성 요소.

GitHub에서 보기

프로젝트 소개

일반화된 Bitey의 업데이트 메커니즘: 필요하지 않은 권한을 요청하는 대신 자체적으로 업데이트하고 나중에 그렇게 말하는 PWA입니다.

복사 sw.js 그리고 pwa-update.js 앱의 웹 루트에 연결하고 연결합니다. 빌드 단계도 없고, 번들러도 없고, 종속성도 없습니다. 이것이 요점입니다. 이러한 앱은 정적 디렉터리입니다.

새로운 서비스 작업자는 탭이 닫힐 때까지 기다리지 않고 즉시 설치하고 활성화합니다. 열려 있는 각 창은 최신 버전으로 원활하게 다시 로드되기 전에 현재 작업을 안전하게 완료합니다.

갤러리

기능

  • ⚡ 즉시 활성화: 열려 있는 브라우저 탭에서 며칠 동안 머무르지 않는 오래된 작업자 없이 새로운 작업자가 설치하고 인계받습니다.
  • 🛡️ 저장되지 않은 작업 보호(isBusy): 작업자는 맹목적으로 탐색하기보다는 질문합니다. 보류 중인 편집 또는 양식 상태가 안전하게 해결될 때까지 페이지 다시 로드를 연기합니다.
  • 🌐 네트워크 우선 신선도: 온라인 요청은 항상 승리하여 배포된 변경 사항이 다음 번 다시 로드 시 적용되도록 하고 오프라인일 때는 캐시로 돌아갑니다.
  • 🔔 클린 세션 저장 알림: 업데이트 플래그를 사용하여 URL 쿼리 문자열을 오염시키는 것을 방지하고 인앱 토스트를 통해 사용자에게 명확하게 알립니다.
  • 🚨 내장 캐시 탈출 해치: 고정된 클라이언트를 위한 긴급 등록 취소 및 캐시 버스트 메커니즘이 포함되어 있습니다.
