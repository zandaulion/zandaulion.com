Hearth OCR

브라우저에서 혈압계 사진을 읽는 실험용 도구입니다. 모든 수치는 직접 확인해야 합니다.

실험적 미리보기 다운로드 · 0.1.0 릴리스 노트 및 SHA-256 GitHub에서 보기

브라우저용 실험 버전

Hearth는 일반적인 세로형 3줄 표시 혈압계의 사진에서 수축기 혈압(SYS), 이완기 혈압(DIA), 맥박을 읽습니다. 사진을 선택하거나 카메라를 사용하고, 표시 영역을 자른 뒤 복사 전에 결과를 수정하세요.

결과를 사용하거나 복사하기 전에 모든 수치를 혈압계 표시와 대조하세요. 이것은 검증된 의료 판독기가 아닌 실험적인 OCR입니다. 새로운 실제 사진의 인식 정확도는 아직 입증되지 않았습니다.

미리보기를 사용해 보세요

첨부된 릴리스 ZIP를 다운로드하고 추출합니다. 여기에는 소스, 두 개의 ONNX 모델 및 브라우저 런타임이 포함됩니다. 계정, npm 설치 또는 모델 교육이 필요하지 않습니다. Python 3.12 이상이 권장됩니다.

추출된 폴더에서 다음을 실행합니다.

python3 prototype/serve.py

동일한 컴퓨터에서 현재 브라우저를 사용하여 로컬 미리보기를 엽니다.

http://127.0.0.1:8765/

서버는 사용자의 컴퓨터에서만 수신합니다. 다른 장치에서 카메라에 액세스하려면 HTTPS와 같은 보안 브라우저 컨텍스트가 필요합니다.

작동 원리

감지기가 디스플레이를 찾고 숫자 인식기가 해당 행을 읽습니다. ONNX 추론은 브라우저 작업자에서 실행됩니다. 일관성 확인 및 자르기 재시도는 불확실한 결과를 거부하거나 재시도할 수 있습니다. 올바른 판독을 보장하지 않습니다.

개인정보 보호 및 오프라인 사용

일반적인 사진 처리는 브라우저의 메모리에 유지됩니다. 앱은 사진을 업로드하거나 저장하지 않습니다. 첫 번째 로드가 완료된 후 서비스 워커는 오프라인 사용을 위해 앱과 모델을 캐시합니다. 로컬 개발 평가 도구는 별도의 워크플로입니다.

재사용 및 통합

원본 코드와 포함된 모델은 AGPL-3.0-only 라이선스를 따릅니다. ONNX Runtime Web은 MIT 라이선스를 유지합니다. 모델 카드는 출처, 체크섬, 한계를 설명하며 통합 가이드는 다른 앱에서 재사용하는 방법을 안내합니다.
