웹용 BP Digitizer

PWA는 같은 프로젝트를 브라우저로 옮겨, 카메라 스캔, 직접 입력, 차트, 내보내기를 제공합니다. 측정값은 브라우저의 IndexedDB에 로컬로 저장되고, 앱은 서버, 계정, 초대 없이 GitHub Pages에서 제공됩니다. 홈 화면에 설치해 가까이 두세요.

GitHub에서 웹 소스 탐색 ↗

웹 앱 내부

이 스크린샷의 측정값과 프로필 정보는 모두 가상입니다.

웹 기능

  • 📱 로컬 우선 및 PWA: 홈 화면에 설치하고 오프라인으로 작동합니다. 판독값은 브라우저의 IndexedDB에 있으며 어디에도 전송되지 않습니다.
  • 📷 기기에서 카메라로 읽기: 세 줄로 표시되는 세로형 혈압계에 카메라를 대면, 브라우저에서 실행되는 모델이 SYS, DIA, 맥박을 읽습니다. 저장 전에 세 값을 모두 확인하며, 확실히 읽을 수 없는 사진은 추측하지 않고 거부합니다.
  • ✏️ 빠른 입장: 마지막 측정값에서 시작하는 슬라이더, 숫자 입력란, 길게 눌러 조절하기.
  • 📈 종합 차트: 추세 차트(수축기 + 확장기, 120/80 기준선) 및 수축기-이완기 분산. 7/30/90일 및 전체 기간.
  • 🧠 스마트 분석: 버스트 평균화는 연속적으로 수행된 판독값을 단일 지점으로 축소합니다. 장치에서 계산된 통찰력(아침 vs 저녁, 범위 내 시간, 정상적인 연속 기록, 컨텍스트 태그)
  • 🩺 임상 논리: AHA 구간(정상 / 주의 / 1단계 / 2단계 / 위기), 평균 동맥압과 맥압, BMI, 건강 프로필에 따른 위험 평가.
  • 📄 내보내기 및 보고서: CSV와 JSON 가져오기와 내보내기, 인쇄하거나 내려받을 수 있는 PDF 보고서.
  • 🔐 암호화 백업: 측정값과 프로필을 암호 문구로 암호화한 파일로 백업하고, 다른 기기에서 복원하세요. 잃어버린 암호 문구는 아무도 복구할 수 없습니다.
  • 🌐 글로벌: Android 앱에서 가져온 12개 언어로, 새로 번역하지 않았으며 아랍어의 오른쪽에서 왼쪽 표시도 지원합니다.

안드로이드용 BP Digitizer

Android 네이티브 앱은 카메라로 혈압계를 읽는 과정을 모두 휴대폰에서 처리하며, 빠른 직접 입력, 추세 보기, Health Connect, PDF 내보내기, 알림도 제공합니다. 인터넷 권한이 없고, Android의 클라우드 백업과 기기 간 이전도 이 앱에서는 꺼져 있어, 내보내지 않는 한 측정값은 휴대폰에만 남습니다. Android 8.0 이상의 ARM64 휴대폰에서 작동합니다.

앱은 F-Droid에 제출되었으며 아직 내려받을 수 없습니다. 대신 웹 버전을 열어보세요 ↗

안드로이드 앱 내부

버전 1.6.2에서 캡처했습니다. 측정값과 프로필 값은 모두 가상입니다.

안드로이드 기능

  • 🏃 활동적인 라이프스타일을 위해 제작되었습니다: 혈압은 걸음 수, 운동, 수면과 함께 핵심적인 건강 지표입니다. 몇 초 안에 기록하고 계속해서 움직이는 루틴의 일부로 유지하세요.
  • ✏️ 몇 초 안에 무료로 판독값을 기록하세요. 빠르고 탭하기 쉬운 슬라이더를 사용하면 수축기, 확장기 및 맥박을 즉시 설정할 수 있습니다. 완전히 무료이고 오프라인으로 작동하며 계정이 필요하지 않습니다. 앱을 처음 열 때부터 추적을 시작하세요.
  • 📷 또는 카메라로 오프라인 스캔: 직접 입력하기 싫으신가요? 혈압계 화면을 찍으면 앱에 내장된 모델이 인터넷 연결 없이 휴대폰에서 값을 읽습니다. 무료이며, 저장하기 전에 항상 값을 확인합니다.
  • 📈 트렌드를 살펴보세요: 일, 주, 월별로 수치가 어떻게 변하는지 확인하세요. 추세선과 3D 분산형 사이를 전환하고 손가락으로 회전하여 수축기, 확장기 및 맥박을 함께 탐색할 수 있습니다. 스마트 "평균" 평활화는 연속 판독값을 하나의 정직한 데이터 포인트로 병합하므로 추세가 현실을 반영합니다. 휴대폰을 가로로 돌리면 두 차트를 나란히 볼 수 있습니다.
  • 🏷️ 무엇이 당신의 숫자를 움직이는지 확인하세요: 운동, 카페인, 짠 식사, 수면 부족, 스트레스 등 맥락에 따라 읽은 내용에 태그를 지정하고 활동과 라이프스타일이 시간이 지남에 따라 수치에 어떻게 영향을 미치는지 알아보세요.
  • ❤️ 헬스 커넥트와 연결: 대시보드에서 측정값을 Android Health Connect로 복사해 혈압을 활동, 운동, 기타 피트니스 데이터와 함께 관리하세요. 선택 사항이며 직접 선택할 때만 이루어집니다.
  • 📄 나만의 기록을 보관하세요: JSON 백업, CSV 파일, 차트와 측정값을 담은 여러 페이지짜리 PDF 보고서를 내보내고, 이 앱이나 웹 버전의 백업을 가져오세요.
  • ⏰ 일관된 습관을 기르세요: 선택적 알림 기능을 사용하면 매일 아침 저녁으로 같은 시간에 기록할 수 있으므로 추세가 완벽하게 유지됩니다.
  • 🔒 비공개 설계: 앱에는 인터넷 권한이 전혀 없습니다. 만들 계정도, 클라우드 가입도 없으며, 아무것도 판매하거나 공유하지 않습니다. 사본을 보관하거나 새 휴대폰으로 옮기려면 JSON 백업을 내보내세요. 당신의 수치는 오직 당신의 것입니다.
  • 🌐 12개 언어: 영어, 아랍어, 중국어, 프랑스어, 독일어, 힌디어, 일본어, 한국어, 포르투갈어, 루마니아어, 스페인어, 우크라이나어.
