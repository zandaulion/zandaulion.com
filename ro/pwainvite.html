O mică consolă pentru gestionarea invitațiilor și dispozitivelor din aplicații web private.

Vezi pe GitHub

Despre proiect

O pagină pentru invitarea și administrarea dispozitivului pentru fiecare aplicație din spatele mecanismului de invitare.

Este singura GUI de administrare — aplicațiile folosite pentru a transporta câte una, ceea ce înseamnă mai multe file deschise și mai multe locuri de reținut. Trăiește în propriul său depozit, deoarece nu aparține niciunei dintre aplicațiile pe care le înfruntă.

Tailscale TLS se termină în fața ascultătorului privat, restricționând accesul administrativ strict la nodurile Tailnet autorizate cu zero puncte finale publice expuse sau parole hardcoded.

Funcționalități

  • 🔑 Ciclul de viață al invitației unificate: Generați, partajați, urmăriți expirarea și monitorizați valorificarea linkurilor de invitație la aplicații între servicii dintr-un singur loc.
  • 📱 Gestionarea dispozitivelor: Inspectați dispozitivele client înscrise, vizualizați marcajele de timp ultimele văzute, atribuiți etichete prietenoase și revocați instantaneu sesiunile compromise.
  • 🔒 Tailnet Private Security: Fără acreditări stocate în codul front-end; autentificat prin injecție de antet de proxy invers privat accesibil doar prin Tailscale.
  • ⚡ PWA cu dependență zero: Aplicație Vanilla JavaScript pe o singură pagină, cu revalidare imediată și zero umflare a cadrului.
