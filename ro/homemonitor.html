Home Monitor

Camerele din casa ta, cu fețele cunoscute recunoscute pe propriul server și o cronologie liniștită a celor care au trecut pe la tine.

Vezi pe GitHub

Home Monitor se găzduiește singur: fiecare persoană rulează propria copie privată.

Despre aplicație

Home Monitor este o privire găzduită de tine asupra camerelor din casă. Un colector mic, aflat lângă camere, preia instantaneele acestora și trimite cadre atunci când ceva se mișcă. Propriul tău server caută apoi persoane și fețe și arată rezultatele într-o aplicație web care se poate instala, cu o cronologie a zilei.

Înregistrarea video continuă rămâne pe cardurile SD ale camerelor; serverul păstrează doar instantanee selectate. Recunoașterea persoanelor și a fețelor rulează pe procesorul serverului, așa că niciun serviciu extern nu primește imaginile tale.

Recunoașterea este o estimare. Home Monitor potrivește fețele cu prudență și lasă neidentificate fețele neclare, dar nu verifică dacă o față este reală, nu garantează o identificare și nu urmărește o persoană de la o cameră la alta. Înregistrează doar persoane care sunt de acord și verifică singur potrivirile neașteptate.

Cum funcționează

  1. Colectează lângă camere. Un dispozitiv mic aflat lângă camere verifică instantaneul fiecăreia la fiecare două secunde și trimite cadre doar când ceva se mișcă, plus unul la fiecare 15 secunde.
  2. Recunoaște pe serverul tău. Serverul găsește persoane și fețe folosind procesorul, fără placă grafică, și compară fețele cu o bibliotecă privată a persoanelor pe care le-ai înregistrat.
  3. Verifică în aplicație. Aplicația web care se poate instala arată cele mai noi instantanee, cine a fost recunoscut și o cronologie a zilei pentru fiecare cameră.
  4. Primește o alertă discretă. Notificările opționale spun doar că s-a întâmplat ceva, fără imagine sau nume, și pot fi amânate pe toate dispozitivele deodată cât timp ești în curte.

Funcționalități

  • Fețe cunoscute: Înregistrează persoane cu acordul lor, iar fiecare eveniment este marcat ca recunoscut, ca față nerecunoscută sau ca persoană a cărei față nu s-a văzut clar.
  • O zi dintr-o privire: Cronologia activității arată evenimentele fiecărei camere de-a lungul zilei, filtrate după cameră, rezultat și oră, alături de perioadele în care o cameră a fost offline sau alertele au fost amânate.
  • Alerte care nu dezvăluie nimic: Notificările push sunt criptate și nu conțin imagini sau nume. Poți primi alerte doar pentru fețele nerecunoscute și le poți amâna pe toate dispozitivele deodată.
  • Acces doar pe bază de invitație: Fiecare telefon sau calculator este activat printr-o invitație și poate fi revocat oricând. Deocamdată, fiecare dispozitiv invitat are acces complet, inclusiv la biblioteca de fețe.
  • Spațiu de stocare care rămâne mic: Evenimentele se șterg după vechime și după dimensiunea totală, fețele înregistrate sunt păstrate separat, iar imaginile private nu intră niciodată în memoria offline a aplicației.
  • Încearcă fără camere: Un demo local desenează scene și persoane inventate, nu folosește recunoaștere reală și se șterge singur când îl oprești.

Cum este construit

Home Monitor are două părți. Colectorul are nevoie doar de Python și Pillow. Serverul rulează Python 3.12 cu FastAPI și SQLite și folosește OpenCV și ONNX Runtime cu trei modele mici: YOLOX-Nano găsește persoane, YuNet găsește fețe, iar SFace le compară. Este gândit pentru procesoare ARM64 fără placă grafică. Tu și colectorul ajungeți la server în mod privat prin Tailscale; accesul public opțional trece prin Cloudflare Tunnel și un listener Caddy securizat. Proiectul este open source sub licența GPL-3.0-or-later.
