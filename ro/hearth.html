Hearth OCR

Un prototip pentru citirea fotografiilor tensiometrului în browser. Verifică personal fiecare valoare pe aparat.

Descarcă versiunea experimentală · 0.1.0 Note de lansare și SHA-256 Vezi pe GitHub

Versiune experimentală pentru browser

Hearth citește tensiunea sistolică (SYS), tensiunea diastolică (DIA) și pulsul din fotografii ale ecranelor verticale obișnuite de tensiometru, cu trei rânduri. Alege o fotografie sau folosește camera, decupează ecranul și corectează rezultatul înainte de copiere.

Verifică fiecare valoare pe tensiometru înainte de a folosi sau copia rezultatul. Acesta este un prototip OCR experimental, fără validare medicală. Precizia recunoașterii pe fotografii noi, realizate în condiții reale, rămâne nedovedită.

Încearcă versiunea experimentală

Descarcă și dezarhivează fișierul ZIP atașat versiunii. Include codul-sursă, două modele ONNX și fișierele necesare rulării în browser. Nu necesită cont, instalare prin npm sau antrenarea modelelor. Se recomandă Python 3.12 sau mai nou.

Din directorul dezarhivat, rulează:

python3 prototype/serve.py

Deschide demonstrația locală într-un browser actualizat, pe același calculator:

http://127.0.0.1:8765/

Serverul ascultă doar pe computerul dvs. Accesul la cameră de pe un alt dispozitiv necesită un context de browser securizat, cum ar fi HTTPS.

Cum funcționează

Un detector găsește ecranul, iar un model de recunoaștere citește cifrele de pe rândurile sale. Inferența ONNX rulează într-un worker al browserului. Verificările de consistență și reluările cu alte decupaje pot respinge rezultatele incerte sau repeta recunoașterea; nu garantează o citire corectă.

Confidențialitate și utilizare offline

În utilizarea obișnuită, fotografiile sunt procesate în memoria browserului: aplicația nu le trimite pe server și nu le salvează. După o primă încărcare completă, un service worker păstrează aplicația și modelele în cache pentru utilizare offline. Instrumentele locale de evaluare pentru dezvoltare reprezintă un flux separat.

Reutilizare și integrare

Codul original și modelele incluse sunt licențiate AGPL-3.0-only. ONNX Runtime Web își păstrează licența MIT. Fișa modelului explică proveniența, sumele de verificare și limitele; ghidul de integrare descrie reutilizarea într-o altă aplicație.
